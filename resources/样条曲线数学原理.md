# 样条曲线数学原理

---

## 1. 什么是样条曲线

**样条 (Spline)** 一词源于造船工业中用来绘制光滑曲线的弹性木条（称为"样条尺"）。在数学和计算机图形学中，样条曲线是指由**分段多项式函数**定义的、具有特定光滑性的曲线。

### 1.1 核心思想

给定一组控制点 `P₀, P₁, P₂, ..., Pₙ`，我们希望构造一条曲线 C(t)，使得：
- 曲线经过（或逼近）这些控制点
- 曲线在连接处具有连续性（光滑过渡）
- 曲线可以用有限的计算代价来求值

### 1.2 样条的分类

| 类型 | 特点 | 代表 |
|------|------|------|
| **插值样条** | 曲线精确通过每个控制点 | Catmull-Rom 样条、自然三次样条 |
| **逼近样条** | 曲线受控制点"吸引"但不一定通过 | B-样条、贝塞尔曲线 |
| **均匀/非均匀** | 参数节点等距/不等距 | 均匀三次 B-样条 vs NURBS |

## 2. 参数曲线基础

### 2.1 参数化

一条三维空间曲线可以表示为：

```
C(t) = (x(t), y(t), z(t))    t ∈ [0, 1]
```

其中 t 是参数，x(t), y(t), z(t) 是 t 的函数。在 2D 情况下，z(t) = 0。

### 2.2 多项式形式

最高效的参数曲线是**多项式曲线**：

```
C(t) = a₀ + a₁t + a₂t² + a₃t³ + ... + aₙtⁿ
```

其中 aᵢ 是向量系数（对于 2D：aᵢ = (xᵢ, yᵢ)）。

三次多项式 (n=3) 是最常用的，因为：
- **一次 (n=1)**：只能表达直线
- **二次 (n=2)**：可以表达抛物线，但拐点固定
- **三次 (n=3)**：可以表达拐点和 S 形曲线，是最低阶的真正"灵活"曲线
- **四次及以上**：计算成本增加，且容易产生不希望的振荡（Runge 现象）

## 3. 贝塞尔曲线 (Bezier Curve)

贝塞尔曲线是计算机图形学中最基础、最重要的曲线形式，由法国工程师 **Pierre Bezier** 在 1960 年代为雷诺汽车公司设计车身曲线时提出。

### 3.1 线性贝塞尔 (n=2 个控制点)

给定两点 P₀ 和 P₁：

```
B(t) = (1 - t)·P₀ + t·P₁    t ∈ [0, 1]
```

这就是 P₀ 到 P₁ 之间的一条**直线段**。

### 3.2 二次贝塞尔 (n=3 个控制点)

给定三点 P₀, P₁, P₂：

```
B(t) = (1 - t)²·P₀ + 2t(1 - t)·P₁ + t²·P₂    t ∈ [0, 1]
```

几何解释 (de Casteljau 算法)：
1. 在 P₀P₁ 上取点 Q₀ = (1-t)P₀ + tP₁
2. 在 P₁P₂ 上取点 Q₁ = (1-t)P₁ + tP₂
3. 在 Q₀Q₁ 上取点 B(t) = (1-t)Q₀ + tQ₁

### 3.3 三次贝塞尔 (n=4 个控制点)

给定四点 P₀, P₁, P₂, P₃（起点、两个控制点、终点）：

```
B(t) = (1 - t)³·P₀ + 3t(1 - t)²·P₁ + 3t²(1 - t)·P₂ + t³·P₃    t ∈ [0, 1]
```

**展开形式：**

```
B_x(t) = (1-t)³·P₀x + 3t(1-t)²·P₁x + 3t²(1-t)·P₂x + t³·P₃x
B_y(t) = (1-t)³·P₀y + 3t(1-t)²·P₁y + 3t²(1-t)·P₂y + t³·P₃y
```

**性质：**
- B(0) = P₀，B(1) = P₃（端点插值）
- 在 t=0 处的切线方向 = 3(P₁ - P₀)（指向第一个控制点）
- 在 t=1 处的切线方向 = 3(P₃ - P₂)（从第二个控制点指来）
- 曲线包含在四个控制点的凸包 (convex hull) 内

### 3.4 伯恩斯坦多项式

贝塞尔曲线的基函数是**伯恩斯坦多项式 (Bernstein Polynomials)**：

```
Bᵢⁿ(t) = C(n, i) · tⁱ · (1 - t)ⁿ⁻ⁱ

其中 C(n, i) = n! / (i! · (n - i)!)  是二项式系数
```

n 次贝塞尔曲线：

```
B(t) = Σ(i=0 to n) Bᵢⁿ(t) · Pᵢ
```

三次 (n=3) 的伯恩斯坦基函数：

```
B₀³(t) = (1 - t)³           ← P₀ 的权重
B₁³(t) = 3t(1 - t)²         ← P₁ 的权重
B₂³(t) = 3t²(1 - t)         ← P₂ 的权重
B₃³(t) = t³                 ← P₃ 的权重
```

重要：对于任意 t，所有权重之和恒为 1（单位分解性）。

### 3.5 贝塞尔曲线的局限

- **不经过中间控制点**：只有端点被精确插值
- **全局性**：移动一个控制点会影响整条曲线
- **高阶时振荡**：控制点较多时使用高次贝塞尔不可取

→ 解决方案：**拼接多段低次贝塞尔曲线**，这正是样条的核心思想。

## 4. Catmull-Rom 样条 (Catmull-Rom Spline)

### 4.1 动机

Catmull-Rom 样条由 **Edwin Catmull** 和 **Raphael Rom** 于 1974 年提出。它是一种**插值样条**——曲线会精确通过每一个控制点（称为"节点" Knot），这与贝塞尔曲线（只有端点被插值）有本质区别。

### 4.2 数学定义

给定 n 个控制点 P₀, P₁, ..., Pₙ₋₁，第 i 段曲线（从 Pᵢ 到 Pᵢ₊₁）是一个三次多项式 Cᵢ(t)，满足：

```
Cᵢ(0)  = Pᵢ                          （起点经过 Pᵢ）
Cᵢ(1)  = Pᵢ₊₁                        （终点经过 Pᵢ₊₁）
Cᵢ'(0) ∝ (Pᵢ₊₁ - Pᵢ₋₁)             （起点切线平行于前后点连线）
Cᵢ'(1) ∝ (Pᵢ₊₂ - Pᵢ)               （终点切线平行于前后点连线）
```

**标准 Catmull-Rom** 下：

```
Cᵢ'(0) = ½(Pᵢ₊₁ - Pᵢ₋₁)
Cᵢ'(1) = ½(Pᵢ₊₂ - Pᵢ)
```

### 4.3 矩阵形式

第 i 段 Catmull-Rom 样条的矩阵表示：

```
               [ -1   3  -3   1 ]   [ Pᵢ₋₁ ]
Cᵢ(t) = ½ · [t³ t² t 1] · [  2  -5   4  -1 ] · [ Pᵢ   ]
               [ -1   0   1   0 ]   [ Pᵢ₊₁ ]
               [  0   2   0   0 ]   [ Pᵢ₊₂ ]
```

展开验证：
- t=0: C(0) = ½ · [0 0 0 1] · M · P_col = Pᵢ ✓
- t=1: C(1) = ½ · [1 1 1 1] · M · P_col = Pᵢ₊₁ ✓

## 5. Cardinal 样条 (Cardinal Spline) — 本程序所用算法

### 5.1 引入张力参数

**Cardinal 样条**是 Catmull-Rom 样条的推广，引入一个额外参数 τ (tension, 张力) 来控制曲线的松紧程度。

**切线缩放因子**：在 Catmull-Rom 中，切线取 ½，即 τ=0.5。Cardinal 样条将 τ 变为可调参数：

```
Cᵢ'(0) = (1 - τ) · (Pᵢ₊₁ - Pᵢ₋₁) / 2
Cᵢ'(1) = (1 - τ) · (Pᵢ₊₂ - Pᵢ) / 2
```

等价地，令 `α = (1 - τ) / 2`：

```
Cᵢ'(0) = α · (Pᵢ₊₁ - Pᵢ₋₁)
Cᵢ'(1) = α · (Pᵢ₊₂ - Pᵢ)
```

其中：
- τ = 0 → α = 0.5 (标准 Catmull-Rom，最松弛)
- τ = 0.5 → α = 0.25 (中等张力)
- τ = 1 → α = 0 (切线为零，曲线退化为直线段连接)

### 5.2 张力参数的直观意义

| τ 值 | 曲线行为 |
|------|----------|
| **0.0** | 最松弛，曲线弧度最大，U 形回转 |
| **0.5** | 标准 Catmull-Rom（默认值），自然平滑 |
| **1.0** | 完全紧绷，退化为控制多边形（折线） |

τ > 1 时切线反向，产生"环形"效果；τ < 0 时切线夸张放大，曲线过度振荡。

### 5.3 Cardinal 样条 → 贝塞尔转换

WPF 原生支持三次贝塞尔曲线（`BezierSegment`），但不直接支持 Catmull-Rom 或 Cardinal 样条。因此需要将 Cardinal 样条**等价转换**为三次贝塞尔形式。

#### 数学推导

对于第 i 段曲线（从 P₁ = Pᵢ 到 P₂ = Pᵢ₊₁），已知：
- 起点：B₀ = P₁
- 终点：B₃ = P₂
- 起点切线：T₁ = α · (P₂ - P₀)，其中 α = (1 - τ) / 2
- 终点切线：T₂ = α · (P₃ - P₁)

三次贝塞尔满足：
- B'(0) = 3(B₁ - B₀) = T₁ → **B₁ = B₀ + T₁ / 3 = P₁ + α·(P₂ - P₀) / 3**
- B'(3) = 3(B₃ - B₂) = T₂ → **B₂ = B₃ - T₂ / 3 = P₂ - α·(P₃ - P₁) / 3**

代入 α = (1 - τ) / 2：

```
B₁ = P₁ + (1 - τ)(P₂ - P₀) / 6
B₂ = P₂ - (1 - τ)(P₃ - P₁) / 6
```

#### 在本程序中的实现

本程序使用了一个简化版本，定义 `tension` 为 `τ ∈ [0, 1]`，直接代入 `τ / 6`：

```csharp
double factor = tension / 6.0;
Point cp1 = new Point(
    p1.X + (p2.X - p0.X) * factor,
    p1.Y + (p2.Y - p0.Y) * factor
);
Point cp2 = new Point(
    p2.X - (p3.X - p1.X) * factor,
    p2.Y - (p3.Y - p1.Y) * factor
);
```

**对应关系**：本程序的 `factor = tension / 6` 相当于 `τ / 6`。当 tension=0.5 时，factor = 1/12 ≈ 0.0833，对应标准 Catmull-Rom 的 α/3 = (0.5)/3 = 1/6 的一半 —— 实际上本程序使用的参数可以更精细地控制。

更精确地说，本程序的 tension 等价于 Cardinal 样条中 α = tension/2：
- 当 tension = 0：α = 0，无张力（直线）
- 当 tension = 0.5：α = 0.25
- 当 tension = 1：α = 0.5（标准 Catmull-Rom）

## 6. 连续性 (Continuity)

样条曲线的重要性质是各段之间的**光滑程度**，由连续性阶数衡量。

### 6.1 参数连续性 (Cᵏ)

- **C⁰ 连续性**：曲线不间断，相邻段共享端点
  - `Cᵢ(1) = Cᵢ₊₁(0)`
- **C¹ 连续性**：一阶导数连续，切线方向连续（速度大小可变）
  - `Cᵢ'(1) = Cᵢ₊₁'(0)`
- **C² 连续性**：二阶导数连续，曲率连续

### 6.2 几何连续性 (Gᵏ)

比参数连续性弱，只关心几何形状，不关心参数化速度。

- **G⁰**：同 C⁰
- **G¹**：切线方向相同，但大小可以不同
  - `Cᵢ'(1) ∥ Cᵢ₊₁'(0)`（平行即可）
- **G²**：曲率连续

### 6.3 Cardinal 样条的连续性

Cardinal 样条具有 **C¹ 连续性**：
- 相邻段共享端点 → C⁰ ✓
- 相邻段在共享端点处切线相同（因为切线由相同的前后点决定）→ C¹ ✓
- 二阶导数不连续 → C² ✗

这使得 Cardinal 样条**视觉上是光滑的**，但曲率可能在节点处有跳跃。

## 7. B-样条 (B-Spline) 简介

**B-样条 (Basis Spline)** 是样条理论中最重要的推广。

### 7.1 定义

k 阶 (order k, 次数 k-1) B-样条由 n+1 个控制点 P₀...Pₙ 和 n+k+1 个节点 t₀...tₙ₊ₖ 定义：

```
C(t) = Σ(i=0 to n) Nᵢ,ₖ(t) · Pᵢ
```

其中 Nᵢ,ₖ(t) 是第 i 个 k 阶 B-样条基函数，由 **Cox-de Boor 递推公式**定义：

**k=1 (0 次)**：
```
Nᵢ,₁(t) = { 1  若 tᵢ ≤ t < tᵢ₊₁
          { 0  否则
```

**k>1 (高阶递推)**：
```
Nᵢ,ₖ(t) = (t - tᵢ) / (tᵢ₊ₖ₋₁ - tᵢ) · Nᵢ,ₖ₋₁(t)
         + (tᵢ₊ₖ - t) / (tᵢ₊ₖ - tᵢ₊₁) · Nᵢ₊₁,ₖ₋₁(t)
```

### 7.2 B-样条性质

- **局部支撑性**：Nᵢ,ₖ(t) 只在 [tᵢ, tᵢ₊ₖ] 内非零 → 移动一个控制点只影响局部
- **非负性**：Nᵢ,ₖ(t) ≥ 0
- **单位分解**：Σ Nᵢ,ₖ(t) = 1
- **可微性**：在节点处为 Cᵏ⁻ᵐ⁻¹ 连续（m 为节点重复度）

### 7.3 NURBS

**非均匀有理 B-样条 (NURBS)** 是 B-样条的有理推广：

```
C(t) = Σ wᵢ · Nᵢ,ₖ(t) · Pᵢ / Σ wᵢ · Nᵢ,ₖ(t)
```

每个控制点有权重 wᵢ。NURBS 可以精确表达圆锥曲线（圆、椭圆、抛物线等），而纯多项式 B-样条只能逼近。NURBS 是 CAD 行业标准（如 IGES、STEP 格式）。

## 8. de Casteljau 算法

**de Casteljau 算法**是计算贝塞尔曲线上点的数值稳定方法，通过递归线性插值求值。

### 对三次贝塞尔曲线 B(t) (t ∈ [0, 1])

```
第 0 级: P₀⁰ = P₀,  P₁⁰ = P₁,  P₂⁰ = P₂,  P₃⁰ = P₃
第 1 级: P₀¹ = (1-t)P₀⁰ + tP₁⁰
         P₁¹ = (1-t)P₁⁰ + tP₂⁰
         P₂¹ = (1-t)P₂⁰ + tP₃⁰
第 2 级: P₀² = (1-t)P₀¹ + tP₁¹
         P₁² = (1-t)P₁¹ + tP₂¹
第 3 级: P₀³ = (1-t)P₀² + tP₁²   ← B(t) = P₀³
```

每个中间点都是相邻两点的线性插值，算法非常稳定，不会出现高次多项式直接求值的数值误差。

### 几何意义

de Casteljau 算法等价于反复"切角"：连接相邻控制点的线段，在比例 t 处取点，形成新的多边形；重复此过程直到只剩一个点，即为 B(t)。

## 9. 三次样条的其它变体

### 9.1 自然三次样条 (Natural Cubic Spline)

要求曲线经过所有节点，并且在两个端点处**二阶导数为零**（C² 连续）。解一个三对角线性方程组获得所有中间切向量。

### 9.2 Hermite 样条

由两个端点和两个端点处的切向量唯一定义：

```
H(t) = (2t³ - 3t² + 1)P₀ + (t³ - 2t² + t)T₀ + (-2t³ + 3t²)P₁ + (t³ - t²)T₁
```

其中 P₀, P₁ 是端点，T₀, T₁ 是端点处的切向量。

Hermite 基函数 (三次)：

```
h₀₀(t) = 2t³ - 3t² + 1    ← P₀ 的权重
h₁₀(t) = t³ - 2t² + t      ← T₀ 的权重
h₀₁(t) = -2t³ + 3t²        ← P₁ 的权重
h₁₁(t) = t³ - t²            ← T₁ 的权重

H(t) = h₀₀(t)·P₀ + h₁₀(t)·T₀ + h₀₁(t)·P₁ + h₁₁(t)·T₁
```

### 9.3 Kochanek-Bartels 样条

Cardinal 样条的进一步推广，额外引入两个参数：
- **bias (偏斜)**：控制切线偏向哪一侧
- **continuity (连续性)**：控制切线的对称性

常用于关键帧动画中调节运动曲线的"性格"。

## 10. 实践要点

### 10.1 边界处理

对于有 n 个控制点的 Cardinal 样条（n-1 段），边界段 (i=0 和 i=n-2) 缺少一侧的邻居点。常用策略：

| 策略 | 方法 |
|------|------|
| **钳制** | 缺失点用自身替代：P₋₁ = P₀, Pₙ = Pₙ₋₁ |
| **反射** | 镜像反射：P₋₁ = 2P₀ - P₁ |
| **周期性** | 首尾相连：P₋₁ = Pₙ₋₂, Pₙ = P₁ |

本程序默认使用**钳制**策略（最简单的实现，曲线在端点处自然停止）。

### 10.2 曲线求值效率

- **预计算**：如果控制点不变，可以预计算矩阵系数
- **自适应步长**：弯曲大的地方多取点，平直的地方少取点
- **GPU 渲染**：现代 GPU 原生支持贝塞尔曲面细分

### 10.3 数值精度

直接使用 Bernstein 多项式在高次 (>10) 时误差放大。对于高次曲线，应使用 de Casteljau 算法或分段低次拼接。

## B. 本程序算法速查

```
输入: n 个控制点 P₀...Pₙ₋₁, 张力参数 τ ∈ [0, 1]
输出: n-1 段三次贝塞尔曲线

for i = 0 to n-2:
    P_prev  = (i == 0)   ? P₀  : Pᵢ₋₁
    P_cur   = Pᵢ
    P_next  = Pᵢ₊₁
    P_nnext = (i == n-2) ? Pₙ₋₁ : Pᵢ₊₂

    factor = τ / 6

    CP1 = P_cur + (P_next - P_prev) × factor
    CP2 = P_next - (P_nnext - P_cur) × factor

    第 i 段贝塞尔: [B₀=P_cur, B₁=CP1, B₂=CP2, B₃=P_next]
```

张力参数与 Cardinal 样条的关系：`α = (1 - τ_cardinal) / 2`，本程序的 `tension` 与 Cardinal τ 的关系为 `tension_program ≈ τ_cardinal`（近似等价）。

控制点数量与贝塞尔段数的关系：**n 个控制点 → n-1 段三次贝塞尔曲线**。
