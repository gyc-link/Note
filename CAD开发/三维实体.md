#### 1.创建标准形状的三维实体

.NET提供了多种创建三维实体的方法
- 拉伸、放样、扫掠、旋转操作创建实体。
- 通过布尔运算所提供的交、并、差操作，能够根据已有的实体"组合"出更加复杂形状的实体。
- 可以通过"剖切"的方法处理实体

>扫掠是沿着路径形状不变
>放样从起点到终点，路径中各个截面形状可以变化
##### 1.1 三维实体类名

各种三维实体的类名均是Soild3d，该类仅提供一个无参数的构造函数，用于创建一个空实体，在构造Solid3d对象之后，必须使用其成员函数来完成实体的创建。

###### 1.1.1 长方体

`public virtual void CreateBox(double lengthAlongX, double lengthAlongY,double lengthAlongZ)`

该函数会创建一个**中心位于世界坐标系WCS原点**的长方体，长宽高分别平行于WCS的X Y Z 轴，可以通过矩阵变化的方法实现改变位置。

###### 1.1.2 圆锥体

.NET并未直接提供创建圆锥体的方法，而是将其包含在创建平截头体的CreateFrustum函数中

`public virtual void CreateFrustum(double height, double radiusAlongX, double radiusAlongY, double topRadius)`

height表示平截头体的高度，radiusAlongX表示底面在X轴方向的半径，radiusAlongY表示底面在Y轴方向的半径，topRadius表示顶面在X轴方向的半径。

为保证生成的平截头体的母线都是直线，顶面在Y轴的半径根据radiusAlongX与topRadius的比例自动算出的。

>椭圆的本质定义通常是：椭圆是平面内到两个定点（焦点F1、F2）的距离之和等于常数（2a）的点的集合。其中焦点位于长轴上且半焦距c等于$\sqrt{a^2-b^2}$

###### 1.1.3 棱柱、棱锥与棱台

`public virtual void CreatePyramid(double height, int sides, double radius, double topRadius)`

height表示棱柱、棱锥或棱台的高度，sides表示棱数，radius表示底面外接圆的半径，topRadius表示顶面外接圆的半径

###### 1.1.4 其他标准形状的三维实体

球体、圆环体、楔体

##### 1.2 创建过程中注意的点

###### 1.2.1 矩阵乘法

具体参考[矩阵](../数学/线性代数/矩阵.md)
对于 `TransformBy(M1 * M2)`：
1. **执行顺序**：**先执行 `M2`，再执行 `M1`**。
2. **数学原理**：如果把物体的一个点设为 ***P***，变换过程其实是$P'=M1×M2×P$ 。M2紧贴着点P，最先起作用。

###### 1.2.2 Martix3d的旋转静态函数
- 返回**绕经过中心点**、**方向为指定向量的轴**（旋转轴）旋转给定角度所对应的旋转矩阵。
- 旋转正方向由右手定则决定，即右手握住旋转轴，拇指指向轴的正方向，此时四指弯曲的方向就是正旋转方向。
- 右手坐标系，CAD的默认世界坐标系是右手坐标系，拇指指向X轴正方向，食指指向Y轴正方向，中指指向Z轴正方向。

###### 1.2.3 参数设置
- 禁止输入很小的参数值，比如长方体中的长宽高参数
- 兼顾CAD命令的使用习惯，输出参数可以是负值
- 因此，对于CreateFrustum等函数，height必须是正值，如果用户输入负值，为了达到期望的效果，可以进行三维镜像操作。
	- `Plane miPlane = new()`生成用于三维镜像的平面，根据三点生成。
	- 以圆锥为例，可以使用圆锥底面的圆心，x轴正方向上的点和y轴正方向上的点。

#### 2.三维实体的拉伸、旋转及布尔操作

##### 2.1 拉伸

`public virtual void Extrude(Region region, double height, double taperAngle)`
其中，region表示拉伸截面，height表示拉伸的高度，taperAngle表示锥度角，正负二分之$\large \pi$之间。

>如果设置了锥度角，底面region只能由直线、圆、圆弧组成
>G1连续，即连接点处的切线必须相等，不能是由突变的，看上去像是尖角。
>所以如果是矩形那样有尖角的，可以做一个微小的圆角，能够满足G1连续。
>拉伸过程中不能自交

`public virtual void ExtrudeAlongPath(Region region, curve path, double taperAngle)`
path表示拉伸的路径曲线

##### 2.2 旋转

`public virtual void Revolve(Region region, Point3d axisPoint, Vecotr3d axisDir, double angleOfRevolution)`
region表示旋转截面，axisPoint表示旋转轴的起点，axisDir表示旋转轴的方向矢量，angleOfRevolution表示旋转角度（弧度）

##### 2.3 布尔操作

`public virtual void BooleanOperation(BooleanOperationType operation, Solid3d solid)`
solid是要参与布尔运算的另一个实体
参与布尔运算的两个三维实体必须处于打开为写的状态。

>布尔操作成功后，跟面域一样会删除参数中solid的shapeMnager对象。
>创建面域的曲线必须是封闭且不能是数据库中打开的曲线，不要记混了。

#### 3.扫掠与放样

`public virtual void CreateSweptSolid(Entity sweepEntity, Entity pathEntity, SweepOptions sweepOptions)`

sweepEntity表示要扫掠的对象，pathEntity表示要扫掠的路径，sweepOptions表示扫掠的选项。

由于SweepOptions本身不可直接修改，需要新建一个扫掠选项构建器，new SweepOptionsBuilder()，通过它设置参数。
- SweepOptionsBuilder对象的TwistAngle属性，表示设置扭转角度，是一个全程总偏移的概念，起点旋转角度是0的话，终点正好旋转到设置的角度，中间是均匀的。
- SweepOptionsBuilder对象的ToSweepOptions()方法会将设置好的参数打包生成最终的SweepOptions对象。

>莫比乌斯环可以通过扫掠两个起点旋转角度是0，终点旋转角度是90度模型组成。

crossSectionCurves表示要放样的截面对象集合，guideCurves表示放样的引导线集合，pathCurve表示放样的路径，loftOptions表示放样的选项。

#### 4.三维实体的边与面

如果要对三维实体进行修改，如着色边、拉伸面、圆角、倒角等操作，往往要对其边和面进行操作。

##### 4.1 边子实体

###### 4.1.1 子实体Id和子实体全路径

PromptSelectionOptions有一个布尔属性是ForceSubSelections，**设置为True时可以得到子实体集合**。

由选择集对象得到子实体Id

```csharp
var sObj = psr.Value[0];
var sSubObjs = sObj.GetSubentities(); 
var edgeSubId = sSubObjs[0].FullSubentityPath.SubentId;
```

以上各个变量分别是SelectedObject对象、 SelectedSubObject[]对象和SubentityId对象

>**注意：** 这里的子实体Id并不是数据库中的ObjectId。

由子实体Id得到其子实体全路径
- `var solid3dIds = new ObjectId[]{solid3d.ObjectId};`
- `var edgePath = new FullSubentityPath(solid3dIds,edgeSubId)`

由子实体全路径得到其子实体Id
`var edgeSubId = edgePath.SubentId;`

**FullSubentityPath**结构体用于定位嵌套子实体的唯一标识，由两部分组成
- **Object ID 路径** (Array): 描述嵌套层级的 ObjectId 数组。若实体非嵌套，则仅包含该实体自身的 ObjectId；若实体嵌套在块中，则按从外到内的顺序包含各级 BlockReference 的 ObjectId，最后指向该实体。（通过GetObjectIds方法获得路径数组）
- **Subentity ID**:该子实体在所属实体内部的特定标识（如某条边或某个面）。

###### 4.1.2 graphics system

>任何一个Entity子类的实体都可以使用gs（graphics system）标记值来确定选择实体的某一部分，这个方法可以方便地选择三维实体的边。

Solid3d的父类Entity有一个GetSubentityPathsAtGraphicsMarker成员函数，通过gs标记返回其子实体全路径数据`FullSubentityPath[]`，得到某一个具体的FullSubentityPath后，再通过其SubentId，可以得到其子实体Id（SubentityId）

##### 4.2 面子实体

面子实体的选择与边子实体的选择方法基本相同，需要额外将PromptSelectionOptions类的SinglePickInSpace属性也设置为True。作用是允许在一个空白处拾取。

>可以通过对边子实体的选择，获得该边的面子实体。

##### 4.3 着色边、拉伸面

选择配置设置
```csharp
pso.SingleOnly = true;           // 单选
pso.ForceSubSelections = true;   // 强制子实体选择
pso.SinglePickInSpace = true;    // 允许在一个“空白”处拾取
```

拿到子实体的Id后，使用Solid3d类的SetSubentityColor函数进行着色。ExtrudeFaces进行面拉伸

>Solid3d类的Highlight可以进行边的高亮，Unhighlight取消高亮

#### 6.BREP

##### 6.1 Brep是什么？
边界表示
cad的BRep API ，在acdbmgdbrep的dll程序集里
能分析和处理 `Solid3d`、`Region` 等实体的内部几何与拓扑结构。

BRep 不是单纯的几何集合，而是一个带拓扑关系的边界图。
Loop 本身就是环。
Edge 通过 Vertex 首尾相连。
Face 通过 Loop 得到边界。
Shell 通过 Face 围成表皮。
Complex 通过 Shell 表示一个连通体。


BRep 类提供了一系列获取 Shell、Face、Loop、Edge、Vertex 等集合的方法。

这些集合很多不是普通 List，而是底层拓扑结构的可遍历视图。
例如 GetVerticesStartingFrom(Vertex startFrom)，就是传入当前 Brep 中的一个合法起始 Vertex，
然后创建 BrepVertexCollection。

这个 Collection 保存 Brep 引用和起始 Vertex，
真正遍历时由 Enumerator 从这个起点出发，
沿着 BRep 的拓扑关系逐个返回 Vertex。
