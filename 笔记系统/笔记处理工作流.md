# 笔记处理工作流

核心原则：**不要「提炼」，要「路由」**。提炼需要深度思考 → 大脑抗拒 → 不做。路由只需要做选择题 → 门槛低 → 能坚持。

---

## 一、判断树（处理任何一段笔记内容）

```
看到一段内容 →
  ├─ 以后还会用到吗？
  │   └─ 不会 → ~~直接划掉~~（别犹豫，80% 的内容都不需要留）
  │
  ├─ 会用到 → 它属于哪个已有主题？
  │   ├─ 有明确的已有主题 → 直接粘贴过去，加 [[日期链接]]，完事
  │   ├─ 是全新的独立主题 → 新建一个主题文件，标 draft
  │   └─ 不确定归哪 → 扔进 [[随手记收件箱]]
  │
  └─ 它是纯备忘/待办？
      └─ 放进「明日计划」或直接删掉，别让待办冒充知识
```

关键规则：
- **路由不等于重写**。粘贴过去就行，不用当场精修。精修是以后的事。
- **一个段落只做一个决定**。不要边路由边改措辞。
- **不确定的统统丢收件箱**。收件箱不是垃圾箱，是「暂未归类」。

---

## 二、每天 2 分钟收尾

写完当日笔记后，做三件事：

| 步骤 | 动作 | 耗时 |
|------|------|------|
| 1. 划 | 快速扫描今天写的内容，把明显没用的 ~~划掉~~ | 30s |
| 2. 标 | 值得保留的段落前打 `★` | 30s |
| 3. 归 | 每个 `★` 段落问自己：「它属于哪个已有主题？」→ 能回答就当场移过去 | 1min |

> 如果第 3 步当场做不完（比如需要打开多个文件），就先全部丢进收件箱，周末再归。

---

## 三、随手记处理管道

随手记收件箱是 `每天的零散记录/随手记收件箱.md`。

### 写入规则
- 每条一行，格式：`- [YYYY.M.D] 内容`
- 不要修饰，不要分类，不要多想。写下来就是胜利。

### 处理规则（每次打开收件箱时）
对每条记录只问一个问题：

> **「这条内容能挂到哪个已有的主题文件上？」**

- 能回答 → 剪切过去，从收件箱删除
- 不能回答 → 留着。积累到 3 条同类内容时，自然就知道归哪了。

### 清理规则
- 任何条目在收件箱里待超过 **2 周** 还没被归类 → 直接删掉。不重要。

---

## 四、主题文件的「接收端」准备

每次往主题文件里粘贴内容时，按三段式处理：

```
### 小标题

粘贴的原始内容（不用改）

> 一句话：这段内容对我有什么用 / 我当初为什么记它
```

「一句话」是唯一需要动脑的地方，但只写一句，不写多。

---

## 五、常见卡住的场景

| 卡住的感觉 | 实际原因 | 解法 |
|-----------|---------|------|
| 「不知道该归哪」 | 分类太粗或太细 | 先丢收件箱，同类出现 3 次再建主题 |
| 「觉得每段都重要」 | 决策疲劳 | 强制只标 3 个 ★，剩下的划掉或丢收件箱 |
| 「不想打开那么多文件」 | 操作摩擦大 | 当天只归一类内容，其余全丢收件箱 |
| 「归过去也没用，照样忘」 | 缺少检索练习 | 归完后顺手把关键点写成闪卡问答 |
