### 2.4 每周 review 习惯

目标：日常笔记是收件箱，主题笔记是长期记忆。

每周花 20 分钟：
1. 翻这周的 daily notes
2. 值不值得保留？→ 提炼到对应主题文件，用 `[[链接]]` 关联
3. 不值得保留？→ 不用管
4. 主题文件有了新内容？→ 顺手加几条闪卡问答

### 2.5 编辑器主次确定

Obsidian 和 VS Code 都能写 Markdown，但链接格式有差异。

选择一：以 Obsidian 为主，用 WikiLink `[[]]`，VS Code 辅助（你已经配置了相对路径兼容）
选择二：以 VS Code 为主，坚持相对路径 `[file](./file.md)`

> 你在 [2026-5-8 Obsidian兼容、SSH连接.md](../每天的零散记录/带主题/2026.5.8%20Obsidian兼容.md) 里刚解决了链接兼容问题。选择一个为主、另一个为辅助即可。

### 2.6 Dataview 动态聚合（可选）

Obsidian Dataview 插件可以根据 frontmatter 自动汇总。例如在 MOC 里：

```dataview
LIST FROM #cad WHERE status = "evergreen"
```

不需要手动维护索引，打标签就行。这个不急，等 MOC 写完、frontmatter 回填完毕后再引入。
