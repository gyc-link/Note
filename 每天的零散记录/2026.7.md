## 单例设计模式

保证一个类只有一个实例，且易于被访问。

某一个类只能有一个实例
自行创建这个实例
像整个系统提供整个实例

单例模式是一种对象创建模式

拥有一个私有构造函数，用户无法通过new关键字直接实例化，并且包含一个静态私有成员变量与静态公有的工厂方法
这个工厂方法负责检验实例的存在性并实例化自己，然后存储在静态成员变量中，以确保只有一个实例被创建。


```csharp
    private static HelpManager _instance;  //提供一个自身的静态私有成员变量
    public static HelpManager Instance // 提供一个公有的属性，检验实例的存在性。
    {
        get
        {
            if (null == _instance)
            {
                _instance = new HelpManager();
            }

            return _instance;
        }
    }
```

可以严格控制客户怎样以及何时访问它。

由于在系统内存中只存在一个对象，因此可以节约系统资源，对于一些需要频繁创建和销毁的对象，单例模式可以提高系统的性能

单例模式允许可变数目的实例，可以基于单例模式进行扩展，使用与单例控制相似的方法来获得指定个数的对象实例。

单例模式没有抽象层，csharp里，抽象类是不允许实例化的。
而抽象类易于扩展

算法：
遍历二维点阵的行索引序列，计算相邻行之间的间距，如果一处索引的相邻行间距相同，则将上一处索引，该索引和下一处索引都加入当前的子阵列集合中；
如果不相等，认为均寻区域结束，新建另一个子阵列集合，继续寻找。
最终得到多个子阵列集合，可能包含空的集合。

1、过滤空集合：
- 如果所有集合均为空，则不存在均匀行距子阵列。
- 按索引顺序，两两分组
2、过滤后的结果，行索引是否完整覆盖所有索引
- 如果完整覆盖，说明原二维点阵由多个均匀行距子阵列拼接组成，分组成功。
- 如果没有完整覆盖，进入步骤三
3、找出未被任何子阵列包含的行索引。
- 对每个未覆盖行索引
- 取其前一个相邻行索引，与当前行索引组成一组。
- 取其后一个相邻行索引，与当前行索引组成一组。
- 额外处理一下第一个和最后一个
- 将这些补充组加入最终结果。
