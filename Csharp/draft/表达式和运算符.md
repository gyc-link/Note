### 字面量

字面量（literal）是源代码中键入的数字或字符串，表示一个指定类型的明确、固定的值。

- `bool` 有两个字面量：`true` 和 `false`
- 对于引用类型，字面量 `null` 表示变量没有指向内存中的数据


## 运算符重载

C# 允许为自定义类型定义运算符行为。

```csharp
public static Vector3d operator -(Point3d a, Point3d b);
// 两点相减 → 从 b 指向 a 的向量
```



### char

`char` 是 C# 中表示**单个 UTF-16 代码单元**的值类型。它的核心事实：

| 属性 | 值 |
|------|-----|
| 底层类型 | 16 位无符号整数（`ushort`） |
| 大小 | 2 字节 |
| 范围 | `U+0000` ~ `U+FFFF` |
| 分类 | 值类型 |

```csharp
char c = 'A';
int num = c;              // num = 65（隐式转换）
char next = (char)(c + 1); // next = 'B'
```

- 字符 `'A'` → Unicode 码点 `U+0041` → UTF-16 编码 `0x0041`
- `char` 既是**字符**，也是**代表这个字符编码的数字**——两者是同一个 16 位值的不同解读

#### char 与 string

- `string` 是引用类型，内部存储为 `char[]` 数组
- 可以通过索引器取单个 `char`：`string s = "hello"; char c = s[0]; // 'h'`
- 对于基本多文种平面（BMP）之外的罕见字符（如某些 emoji），需要**两个 `char`**（代理对）来表示一个 Unicode 码点
- C# 中，单引号只能包含**一个字符**

#### char 与 int 之间的隐式转换（底层）

`char` → `int` 是**隐式数字转换**（不丢失信息）：

> 底层做了：CPU 开辟 4 字节新空间 → 把 2 字节的 `char` 复制过去 → 高位补零

这不是继承关系（`char` 并不是 `int` 的子类）。对比：

| 转换类型 | 底层发生了什么 |
|----------|---------------|
| 值类型 `char` → `int` | **内存重组**：开辟新空间、复制、高位补零 |
| 引用类型子类 → 基类 | **不碰数据**：同一个对象，换一个受限的视角 |
| 用户自定义隐式转换 | **调用静态方法**，返回一个全新的对象 |

#### 常用方法

> [!NOTE]
> `System.Char` 的功能方法**全部是静态的**。`char` 变量自身只有从 `ValueType` / `IComparable` 继承来的实例方法。

##### 静态方法

**判断类**（参数 `char c`，返回 `bool`）

| 方法 | 用途 |
|------|------|
| `Char.IsLetter(c)` | 是否字母（A-Z、a-z 及各国字母） |
| `Char.IsDigit(c)` | 是否十进制数字 `0-9` |
| `Char.IsLetterOrDigit(c)` | 字母或数字 |
| `Char.IsNumber(c)` | 是否数字（含上标、分数等，比 `IsDigit` 更宽） |
| `Char.IsWhiteSpace(c)` | 是否空白（空格、制表符、换行等） |
| `Char.IsUpper(c)` | 是否大写字母 |
| `Char.IsLower(c)` | 是否小写字母 |
| `Char.IsPunctuation(c)` | 是否标点 |
| `Char.IsSymbol(c)` | 是否符号（数学符号、货币符号等） |
| `Char.IsSeparator(c)` | 是否分隔符（空格、不间断空格等） |
| `Char.IsControl(c)` | 是否控制字符（如 `\0`、`\t`、`\r`） |
| `Char.IsSurrogate(c)` | 是否代理对的一半 |
| `Char.IsHighSurrogate(c)` | 是否代理对高位 |
| `Char.IsLowSurrogate(c)` | 是否代理对低位 |

```csharp
Char.IsLetter('A');    // true
Char.IsDigit('5');     // true
Char.IsDigit('五');    // false — 中文数字不算 Digit
Char.IsNumber('五');   // false — 中文字符也不在 Unicode Number 分类里
Char.IsWhiteSpace(' ');// true
Char.IsUpper('A');     // true
```

**转换 / 其他**

| 方法 | 签名 | 用途 |
|------|------|------|
| `Char.ToUpper` | `(char c) → char` | 转大写 |
| `Char.ToLower` | `(char c) → char` | 转小写 |
| `Char.Parse` | `(string s) → char` | 从字符串解析（字符串长度必须为 1） |
| `Char.TryParse` | `(string s, out char) → bool` | 安全解析 |
| `Char.GetNumericValue` | `(char c) → double` | 获取字符的数值（如 `'3'` → `3.0`，`'五'` → `-1` 表示不是数字） |
| `Char.GetUnicodeCategory` | `(char c) → UnicodeCategory` | 获取完整的 Unicode 分类枚举 |
| `Char.ConvertFromUtf32` | `(int utf32) → string` | 把 Unicode 码点转成字符串（可能返回 2 个 char） |
| `Char.ConvertToUtf32` | `(string s, int index) → int` | 从字符串指定位置取完整码点（自动处理代理对） |

```csharp
Char.ToUpper('a');           // 'A'
Char.Parse("X");             // 'X'
Char.TryParse("abc", out _); // false（长度不是 1）
Char.GetNumericValue('5');   // 5.0
Char.ConvertFromUtf32(0x1F600); // "😀"（一个 emoji，内部是 2 个 char 的代理对）
```

##### 继承的实例方法

这些不是 `Char` 独有的，而是从 `ValueType` / `IComparable<char>` 继承来的：

| 方法 | 说明 |
|------|------|
| `c.Equals(obj)` | 值相等比较（装箱开销，建议用 `==`） |
| `c.CompareTo(other)` | 按 Unicode 码点比较大小 |
| `c.ToString()` | 转成长度为 1 的字符串 |
| `c.GetHashCode()` | 返回该 char 的哈希码（等于 `(int)c`） |
| `c.GetTypeCode()` | 返回 `TypeCode.Char`（实现了 `IConvertible`） |

```csharp
char c = 'B';
c.CompareTo('A');  // 1  （'B' > 'A'）
c.CompareTo('C');  // -1 （'B' < 'C'）
c.CompareTo('B');  // 0  （相等）
c.ToString();       // "B"
```
