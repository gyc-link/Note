### 什么是委托


委托实例化的三种方式

委托类型编译后会生成一个类（继承 `MulticastDelegate`），所以实例化委托 = 创建这个类的对象，把**目标对象**和**方法指针**传进去。三种写法本质都是 `new`，只是语法糖程度不同。

>[!tip] 目标对象和方法指针是什么
>委托有Target和Method属性
>![](../../pic/Pasted%20image%2020260608195622.png)
>![](../../pic/Pasted%20image%2020260608195649.png)


**1. `new` 关键字（最原始的写法）**

```csharp
delegate int MyDelegate(int x);

static int Double(int x) => x * 2;

MyDelegate d = new MyDelegate(Double);  // 显式调用编译器生成的构造函数
```

**2. 方法组隐式转换（C# 2.0，最常用）**

```csharp
MyDelegate d = Double;  // 编译器自动推断为 new MyDelegate(Double)
```

直接把方法名赋给委托变量，编译器在背后帮你补上 `new MyDelegate(...)`。平时写代码基本都用这种。

**3. lambda / 匿名方法（最简洁）**

```csharp
MyDelegate d = x => x * 2;                    // lambda
MyDelegate d2 = delegate(int x) { return x * 2; };  // 匿名方法（lambda 的前身）
```

编译器会生成一个匿名方法，然后帮你 `new MyDelegate(匿名方法)`。lambda 捕获外部变量时，编译器还会额外生成一个闭包类。

> [!NOTE] 三种方式的本质都一样
> 最终都是创建一个委托实例，其内部持有**调用列表**（invocation list）——一个有序的方法列表。区别只是代码怎么写。

>[!cite] 补充
>对于使用lambda创建委托实例，对应的Target有下面三种情况
>- lambda没有使用任何外部变量，可以理解成此时的lambda是一个静态方法，委托的Tatget指向null。
>- 捕获了当前类的实例成员，此时编译器会在底层把这个Lambda编译成当前类的一个隐藏实例方法，委托的Tatget指向this。
>- 捕获了局部变量，编译器在底层创造了一个闭包类，此时这个局部变量就变成闭包类的成员字段，lambda就成了它的方法，委托的Tatget就指向这个闭包类。

---

可以认为委托是持有一个或多个方法的对象。且与典型的对象不同的是，可以执行委托，这时候委托会执行它所持有的方法。

委托像是给==某种函数签名起了一个类型名==，然后这个类型的变量可以保存 lambda、匿名函数、普通方法。

委托其实是用来表达某一类相同签名的函数，这些函数的功效各不相同，但是函数的参数列表和返回值类型是一致的。delegate 返回值类型 委托名 （参数列表）
