# 枚举

枚举是值类型，只有一种类型的成员——**命名**的整数值常量。

```csharp
enum TrafficLight
{
    Green,   // 用逗号分隔
    Yellow,
    Red
}
```

每个枚举类型都有一个底层类型，默认为 `int`。编译器对第一个成员赋值为 0，后续成员依次 +1。

如果枚举作为类的字段成员，默认初始化方式是==赋值为第一个成员==。
<!--SR:!2026-10-15,86,270-->

**设置底层类型和显式值**：在枚举名后加冒号和类型名，可以是任意整数类型。成员名不能重复，但值可以重复。

**枚举的核心价值**：
1. 用有意义的名称替代魔法数字，提升可读性
2. 让编译器检查取值范围和类型安全，把"约定"变成"规则"

# 位标志枚举

``` csharp
        [Flags]
        public enum ChamferProcessType
        {
            /// <summary>
            /// 无
            /// </summary>
            None = 0x00,
            /// <summary>
            /// 过焊孔
            /// </summary>
            Hole = 0x01,
            /// <summary>
            /// 圆角
            /// </summary>
            Bead = 0x02,
            /// <summary>
            /// 切角
            /// </summary>
            RightAngle = 0x04,
        }
```

## 为什么需要 位标志枚举？

因为普通的枚举没法同时表达两种状态信息。

### 特性 Flags是什么

告诉c#，这个枚举不是表示一个单处状态，而是一个可以组合的开关。

即
``` csharp
var type = ChamferProcessType.Hole |  ChamferProcessType.Bead;
```

一个变量可以同时保存多个状态。既有过焊孔，又有圆角。

### 为什么数值是1、2、4？

这些数值转成二级制后只有一个位上的数值是1，其余都是0

0×01 --- 0001
0×02 --- 0010
0×04 --- 0100
0×08 --- 1000

### 位运算

![](../../pic/Pasted%20image%2020260727143409.png)

那么type就是 0001跟0010进行 位或 运算， 结果是 0011

所以type里就保存了<span style="color:red;">两种状态信息</span>

### 怎么使用

①特性Flags的其中一个作用，就是能输出组合状态

例如：
```
var type =
    ChamferProcessType.Hole |
    ChamferProcessType.Bead;

Console.WriteLine(type);
```

如果有 `[Flags]`：

输出：

```
Hole, Bead
```

如果没有：

可能输出：

```
3
```

因为它不知道 3 代表什么组合。

② 怎么判断保存的信息里有没有某个类型？

用 位与 运算 

type跟过焊孔进行 位与 运算

``` csharp
if ((type & ChamferProcessType.Hole) != 0)
{
    Console.WriteLine("有过焊孔");
}
```

如果type里保存了过焊孔的信息，那么<span style="color:red;">表示过焊孔的那个信息位上的数字一定都是1</span>，最后计算的结果不为0
