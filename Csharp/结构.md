## 结构 vs 类

结构（struct）和类（class）最核心的区别只有两个：

1. **类是引用类型，结构是值类型**
2. **类支持继承，结构不支持继承**（结构隐式密封，只能实现接口）

## 值类型的行为

因为结构是值类型，所以：
- 赋值时复制整个值，不是复制引用
- 传递给方法时默认传副本（除非用 `ref`）
- 不需要 `new` 也可以使用（字段会被初始化为默认值）
- 存放在栈上（作为局部变量时）或是包含它的对象的内存中

```csharp
struct Point
{
    public int X;
    public int Y;
    
    public Point(int x, int y)
    {
        X = x;
        Y = y;
    }
}

Point a = new Point(1, 2);
Point b = a;        // 完整复制
b.X = 10;           // a.X 还是 1
```

## 什么时候用结构

- 数据量小（16 字节以下是比较公认的建议）
- 逻辑上是一个"值"而非"实体"——比如坐标点、颜色、复数
- 不需要继承层级
- 创建和销毁频繁（结构避免堆分配，减少 GC 压力）

CAD API 里 `Point3d`、`Vector3d`、`Matrix3d` 都是结构。

## 结构的限制

- 不能有无参构造函数（C# 10.0 前）
- 字段不能在声明时初始化（C# 11.0 前）
- 不能继承类，也不能被类继承
- 可以实现接口，但用接口引用结构会导致装箱

## 装箱（Boxing）

结构转 `object` 或接口引用时会发生装箱：把值类型的数据复制到堆上，变成引用类型。装箱有性能开销，且装箱后的修改不影响原来的结构。
