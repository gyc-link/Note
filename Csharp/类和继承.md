## 1. 类的基础

### 1.1 变量 vs 对象

- **变量**：存储位置的名称。值类型变量存数据本身，引用类型变量存指针。
- **对象**：内存中的实际数据，是类的实例。

### 1.2 声明 vs 定义

- **声明**：告诉编译器有这个东西——叫什么、什么类型，但不一定分配内存、不一定实现
- **定义**：给出具体实现。非抽象类的方法体、字段的存储分配都是定义

### 1.3 类的成员

一个类可以包含以下成员：

字段、方法、常量、属性、构造函数、析构函数、索引器、事件、运算符

### 1.4 访问修饰符

| 修饰符 | 访问范围 |
|--------|----------|
| `private` | 仅当前类内部 |
| `protected` | 当前类及其派生类 |
| `internal` | 当前程序集内 |
| `protected internal` | 当前程序集内 OR 派生类 |
| `public` | 任何地方 |

### 1.5 字段

- 字段是类或结构的成员变量
- 引用类型字段默认值是 `null`
- 值类型字段默认值是 `0`（或等价零值）

**const vs readonly：**

| | const | readonly |
|---|---|---|
| 赋值时机 | 编译时（声明处必须赋值） | 运行时（声明处或构造函数中赋值） |
| 存储 | 无存储位置，编译期直接替换 | 有存储位置 |
| 修饰 | 隐式 static | 可以是实例或静态 |
| 适用 | 字面量、数学常量 | 只读但值要到运行时才确定的场景 |

### 1.6 属性（Property）

属性是字段的封装，提供 `get` / `set` 访问器：

```csharp
public int Age
{
    get => _age;
    set => _age = value > 0 ? value : throw new ArgumentException();
}
```

- 静态属性通过类名访问
- 只读属性如果返回值是集合，集合内容仍可以修改

### 1.7 构造与析构

- 构造函数没有返回类型，名字与类名相同
- 静态构造函数无参数、不能有访问修饰符，只能有一个，用于初始化静态字段，在类首次使用前由 CLR 调用
- 析构函数（`~ClassName()`）由 GC 在回收对象时调用，不应主动依赖它释放资源

### 1.8 静态成员

>[!NOTE]
>- 静态成员属于类本身，不属于任何实例
>- 静态类是隐式密封的，不能有实例成员
>- 静态成员在被使用前就会被初始化，生命周期伴随整个应用程序域
>- 通常当作全局“工具箱”使用
>- ```csharp
>public static class MyUtils { }
>public abstract sealed class MyUtils { }//底层CIL代码
>

## 2. 面向对象三大特性

>[!NOTE]- 封装
>藏数据，控访问。把数据和操作数据的方法绑定在一起，通过访问修饰符控制暴露范围

>[!NOTE]- 继承
>- 继承：一个类复用另一个类的代码。派生类拥有基类的所有成员（但不能删除），可以在此基础上扩展

>[!NOTE]- 多态
>- 运行时多态：**父类变量装子类对象**，同一调用表现出不同行为。C# 中通过 `virtual` / `override` 实现。
>- 编译时多态：方法重载、泛型

## 3. 继承

### 3.1 基本规则

- 所有类都直接或间接派生自 `object`
- **单继承**：一个类只能有一个直接基类
- **多接口**：一个类可以实现多个接口
- 冒号 `:` 后跟基类类型，术语叫"基类规格"（base class specification）

### 3.2 向上转型（Upcasting）

派生类对象可以隐式转换为基类引用：

```csharp
Derived d = new Derived();
Base b = d;  // 隐式转换，不需要显式转换
```

>[!NOTE] 
转换后，通过基类变量**无法访问派生类独有的成员**——在**内存视角**下，基类变量"看不到"派生类部分。

### 3.3 向下转型（Downcasting）

基类引用转回派生类需要显式转换，且必须在运行时验证：

```csharp
Base b = new Derived();
Derived d = b as Derived;  // 安全：失败返回 null 而不是抛异常
if (d != null) { ... }

// 或：
if (b is Derived d2) { ... }  // C# 7+ 模式匹配
```

### 3.4 virtual / override / new

```csharp
class Base
{
    public virtual void VMethod() => Console.WriteLine("Base.V");
    public void NMethod() => Console.WriteLine("Base.N");
}

class Derived : Base
{
    public override void VMethod() => Console.WriteLine("Derived.V");  // 覆写
    public new void NMethod() => Console.WriteLine("Derived.N");       // 屏蔽
}

// 行为差异：
Base b = new Derived();
b.VMethod();  // 输出 "Derived.V" —— 看运行时类型（多态）
b.NMethod();  // 输出 "Base.N"    —— 看编译时类型（被屏蔽）
```

**virtual / override 约束：**
- 基类和派生类的方法必须有相同的签名和返回类型
- 必须是相同的可访问性
- 不能覆写 `static` 或非虚方法
- 方法、属性、索引器、事件都可以声明为 `virtual` 和 `override`
- 覆写可以在继承的任何层次出现

>[!NOTE] 最高派生类规则
>如果使用基类引用调用一个被覆写的方法，会执行继承链中**最高派生类**里标记为 `override` 的方法——不只是直接派生类的版本。

如果派生类和基类有相同签名的方法，优先考虑虚方法而非 `new` 屏蔽。

### 3.5 base 关键字

派生类中可以通过 `base` 关键字访问被屏蔽或覆写的基类成员：

```csharp
class Derived : Base
{
    public override void VMethod()
    {
        base.VMethod();  // 先执行基类逻辑
        // 再执行派生类自己的逻辑
    }
}
```

### 3.6 构造函数与继承

- 派生类构造函数执行前，必须先执行基类构造函数
- 如果基类没有无参构造函数，派生类必须用 `base(...)` 显式调用
- 同一个类内构造函数之间用 `this(...)` 链式调用

### 3.7 抽象类（abstract）

参考[abstract](draft/Csharp关键字.md#abstract)

### 3.8 System.Object 的四个核心方法

所有类的最终基类都是 `object`。它提供四个方法，经常被重写：
- `Equals` — 值相等判断（引用类型默认比较引用）
- `GetHashCode` — 哈希码，Dictionary 等结构用它做 O(1) 查找
- `ToString` — 字符串表示
- `GetType` — 返回运行时类型信息

## 4. 扩展方法

用于为密封类或已有类型扩展功能，而不修改其源代码：

```csharp
public static class StringExtensions
{
    public static bool IsNullOrEmpty(this string s) => string.IsNullOrEmpty(s);
}

// 通过实例调用
"hello".IsNullOrEmpty();  // false
```

- 必须声明在非嵌套、非泛型的**静态类**中
- 第一个参数加 `this` + 目标类型
- 通过目标类型的实例调用（不是通过静态类名）

>[!note] 扩展方法是一个语法糖
>编译器会将上述的实例调用转为普通的静态方法调用
>```csharp
>StringExtensions.IsNullOrEmpty("hello")
>```

>[!note] 
>在参数列表里使用this关键字就只有扩展方法这一种情况
