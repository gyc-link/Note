# 正则表达式

用**模式**去描述"你想找的字符串长什么样"。

## 基础字符

| 符号 | 含义 |
| --- | --- |
| `\d` | 任意**单个数字** |
| `.` | 任意**单个字符**（除换行） |
| `\w` | 字母、数字、下划线 |

## 数量限定符

| 符号 | 含义 |
| --- | --- |
| `+` | 前面内容 **1 次及以上** |
| `*` | 前面内容 **0 次及以上** |
| `?` | 前面内容 **0 次或 1 次** |
| `{n}` | 恰好重复 **n 次** |
| `{n,m}` | 重复 **n~m 次** |
| `*?` | 非贪婪匹配 |

## 其他

| 符号 | 含义 |
| --- | --- |
| `^` | 字符串开头；在 `[]` 内是取非操作 |
| `$` | 字符串结尾 |
| `[]` | 字符范围，匹配括号内**任意一个**字符 |
| `()` | 捕获组：框起内容生成捕获组，把多个字符当成一个整体 |
| `(?! )` | 否定前瞻条件判断 |
| `(?<!)` | 否定后顾条件判断 |
| `\b` | **单词边界**锚点 |

## C# 中的正则

统一规范：正则表达式全部写 `@"规则"`。

```csharp
Regex.IsMatch(text, regex)              // 有没有匹配到
Match m = Regex.Match(text, pattern);    // 找一个匹配
MatchCollection ms = Regex.Matches(text, pattern); // 找所有匹配
Regex.Replace(text, pattern, replacement) // 替换
```
