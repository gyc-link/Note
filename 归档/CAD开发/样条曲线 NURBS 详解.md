### 样条曲线（Spline / NURBS）

数学原理见[样条曲线数学原理](../../resources/样条曲线数学原理.md)

样条曲线是一类**通过控制点和节点矢量定义的参数曲线**。CAD 中最常见的形式是 **NURBS**（非均匀有理 B 样条）。

#### 实际意义：为什么非要用样条？

> [!important] 一句话
> **直线和圆弧描述规则形状，样条描述自由形状。** 样条用少数几个控制点 + 数学基函数，生成处处光滑的自由曲线。输出曲线的复杂度远超输入数据的复杂度。
> 用最少的数学数据，完美模拟现实世界中物理材料在受力时产生的最自然，最光滑的弯曲形态。

>[!NOTE] 什么是龙格现象
>高次方程在中间的点能够拟合，但是在两端的边界会产生剧烈震荡


**没有样条就做不了的事：**

| 需求 | 没有样条怎么办 | 样条怎么解决 |
|:---|:---|:---|
| 设计自由曲面（车身、叶片、手机外壳） | 用几百段圆弧拼，连接处不光滑 | 几个控制点，任意阶光滑 |
| 逆向工程（3D 扫描 → CAD 模型） | 无法做 | 拟合点 → 控制点反算 |
| 数控加工（CNC 刀路沿自由曲面走） | 圆弧逼近，误差大 | NURBS 直接输出精确刀路 |
| 网格→曲面（半边结构 → B-rep） | 三角面永远是小平面 | NURBS 重建为精确曲面 |
| 轻量化存储（复杂形状） | 存几万个小三角 | 存几十个控制点 + 节点矢量 |
| **Offset 操作**（`OffsetCurve3d`） | 直线/圆弧偏移后仍是同类 | 样条偏移还是样条，但阶数可能升高 |

**本质差异**：三角网格是**离散近似**（用足够多的小平面"看起来像"曲面），NURBS 是**连续精确**（曲线上任意 t 都有精确的数学值）。这就是为什么 CAD 内核（ACIS、Parasolid）用 NURBS 做核心表示。

**日常开发中的表现**：
1. 客户给的曲线（来自 Rhino/Alias 等工业设计软件）→ AutoCAD 里就是 `Spline` 对象
2. `OffsetCurve3d` 偏移样条 → 数值逼近，非精确公式（[[2026.5.15~17 偏移的一些问题#OffsetCurve3d 内存与拟合陷阱|你已踩过这个坑]]）
3. 放样/扫掠实体（`CreateLoftedSolid` 等）→ 截面和导引线经常是样条
4. CATIA/UG 模型导入 → 底层全是 NURBS，`NurbCurve3d` 是载体

#### 核心组成

| 要素 | 说明 |
|---|---|
| **控制点** `CtrlPts` | 不一定在曲线上，拉拽曲线形状的"磁铁" |
| **拟合点** `FitPts` | 曲线**必须经过**的点（可选，用于插值构造） |
| **阶数** `Degree` | 曲线段的多项式次数（三次 = 3） |
| **节点矢量** `Knots` | 决定参数如何沿曲线分布，定义曲线的**参数域** |
| **权重** `Weights` | NURBS 特有，控制点对曲线的"引力强度" |

#### 拟合点 vs 控制点

两套构造思路：
- **拟合点**：指定"曲线要经过这些点"，引擎反算控制点和节点矢量
- **控制点**：直接操纵曲线的"磁铁"，曲线不经过控制点，只受拉扯

> 一条 Spline 可以同时存 FitPoints 和 CtrlPts。但 `CreateFromGeCurve` 生成的退化曲线有控制点却没拟合点（`NumFitPoints = 0`），参见 [[2026.5.15~17 偏移的一些问题#OffsetCurve3d 内存与拟合陷阱|5.15~17 OffsetCurve3d]]。

#### 定义域（Domain）—— 最关键的概念

样条曲线的**参数域**由节点矢量（Knot Vector）决定。参数 `t` **只能在节点矢量范围内取值**：

$$t \in [\text{knots}[\text{degree}],\ \text{knots}[\text{knots.Count} - 1 - \text{degree}]]$$

```csharp
Spline spline = ...;
double tMin = spline.Knots[spline.Degree];
double tMax = spline.Knots[spline.Knots.Count - 1 - spline.Degree];
```

节点矢量不是均匀的。一个三次 NURBS 的节点矢量可能是：

```
[0, 0, 0, 0,  0.3, 0.5, 0.7,  1, 1, 1, 1]
 └── degree=3 ──┘  └── 内部节点 ──┘  └── degree=3 ──┘
   前 4 个重复          参数"刻度"        后 4 个重复
```

- 首尾重复 `degree+1` 次 → 曲线端点与控制点端点重合（clamped knot vector）
- 中间节点间距不一致 → 参数 t 沿曲线**非均匀**前进

#### 为什么 SetInterval 对不同曲线类型行为不同

不同类型的曲线，底层公式完全不同。这决定了"改参数范围"对它们意味着什么：

$$
\begin{aligned}
\text{直线} &: \quad P(t) = P_0 + t \cdot \vec{v}, \quad t \in (-\infty, +\infty) \\
\text{圆弧} &: \quad P(\theta) = C + R(\cos\theta, \sin\theta), \quad \theta \in (-\infty, +\infty) \\
\text{样条} &: \quad P(t) = \frac{\sum w_i N_{i,k}(t) P_i}{\sum w_i N_{i,k}(t)}, \quad t \in [t_{min}, t_{max}]
\end{aligned}
$$

| 曲线类型            | 底层几何        | SetInterval 行为 |
| --------------- | ----------- | -------------- |
| `LineSegment3d` | 无限直线 → 裁剪窗口 | 域外直线仍存在，任意延长   |
| `CircularArc3d` | 完整圆 → 角度范围  | 域外圆仍存在，多绕几圈    |
| `NurbCurve3d`   | NURBS → 参数域 | 域外**无定义**      |

**直线参数是线性的，圆弧参数是周期的——底层数学自然延伸到域外。样条的参数 t 受限于 B 样条基函数的定义范围，超出节点矢量则基函数无定义，整条曲线无定义。**

CAD 几何内核（Autodesk ShapeManager / ACIS）对解析几何和自由曲线的处理层级不同：
- **解析曲线**（线/圆/椭圆）：数学上有无限定义域，`SetInterval` 扩大范围 → 自动延长或补全
- **自由曲线**（样条/NURBS）：定义域由节点矢量决定，超出 → 内核异常（`InvalidInput` / `Standard_Failure`）

> `Curve3d.SetInterval` 是基类方法，被处理过的 `Curve3d` 不一定能被 `Curve.CreateFromGeCurve` 全部接受——可能导致 `eNotImplementedYet` 异常。

#### 如何延长样条

延长样条不能靠改 interval，必须**物理修改曲线**：
1. **加控制点**：在首/尾加新点，重建节点矢量
2. **转 NurbCurve3d**：`curve3d.Extend(...)` 或手动加控制点 + 调 knot
3. **JoinWith**：两条曲线拼成一条

#### 阶数、控制点数、节点数的关系

$$m = n + p + 1$$
（节点数 = 控制点数 + 阶数 + 1）

NURBS 数学定义焊死的，CAD 不能改。
