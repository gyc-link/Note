## 2026.5.10 — Unity 项目文件管理

Unity 项目是按文件类型建一级目录，必要时在类型目录下按功能分子目录：
- Scripts/ — 代码
- Scenes/ — 场景
- Prefabs/ — 预制体
- Animations/ — 动画片段
- Animators/ — 动画状态机
- Sprites/ — 图片资源
- Docs/ — 文档
- Audio/、Materials/、Editor/、Plugins/、Resources/

## 2026.5.10 — 爬虫（Web Spider）

本质：模拟浏览器行为，按规则批量抓公开数据，替代人工复制粘贴。

工作流程：
- **种子 URL**：起始网址（如首页、列表页）。
- **发 HTTP 请求**：用 `requests`/`curl` 模拟浏览器访问，带 Headers（User-Agent、Cookie）。
- **获取响应**：服务器返回 HTML/JSON/图片等原始内容。
- **解析提取**：用 XPath、CSS 选择器、正则或 BeautifulSoup 抓目标字段（标题、价格、链接）。
- **存储 + 翻页**：存 CSV/JSON/数据库；从页面抓新 URL 入队列，循环爬取。

为什么有些视频的下载按钮是灰色的，爬虫能无视这个直接下载原视频？
用 Playwright + Chromium 能完整加载视频流，不管网站禁不禁止下载（下载按钮是灰色其实是前端限制），视频源码一定会渲染到浏览器里。

## 2026.7~9 — 系统与运行

### Windows 注册表

`Registry` 类：命名空间 `Microsoft.Win32`，程序集 `Microsoft.Win32.Registry.dll`。提供 `RegistryKey` 对象（表示 Windows 注册表中的根键），以及用于访问键/值对的 `static` 方法。

**注册表是系统定义的数据库**，应用程序和系统组件在其中存储和检索配置数据。注册表中存储的数据因 Windows 版本而异；应用程序使用注册表 API 检索、修改或删除注册表数据。

注册表有**五大根键**（对应 `Registry.ClassesRoot`、`CurrentUser`、`LocalMachine`、`Users`、`CurrentConfig`）。

### Roaming 与 Local

- **Roaming**：放小容量的配置文件，会记录登录信息。第一次登录、勾选了"记住密码/自动登录"时，服务器会给本地电脑发一串长的、加密的复杂代码——就是 **Token**，软件把它保存在 Roaming 文件夹里。
- **Local**：放大文件或临时缓存。

### 解释型 vs 编译型

Python 边解释边执行。C# 的路径不同：

```
C# 源码 → 编译器 → IL（中间语言）→ JIT 编译 → 机器码 → CPU 执行
```

C# 是**强类型语言**，要经过编译器编译成中间语言，再经过 JIT 编译成机器码，最终由 CPU 执行。整个过程中，操作系统负责处理内存和线程请求，并调度相关系统资源。

### 测试的层次

**单元测试（Unit Testing）**：对程序中最小可测试单元进行验证的一种软件测试方式。"单元"通常指某个函数、方法或类。

```csharp
int Add(int a, int b) => a + b;

Assert.AreEqual(5, Add(2, 3));
Assert.AreEqual(0, Add(-1, 1));
Assert.AreEqual(0, Add(0, 0));
```

如果有断言失败，说明代码存在 bug，或者与预期不一致。

| 层次 | 测什么 |
| --- | --- |
| 单元测试 | 单个函数 / 方法 / 类 |
| 集成测试 | 多个模块协同工作 |
| 系统测试 | 整个系统 |
| 验收测试 | 是否满足用户需求 |

测试框架负责提供断言、组织用例和报告结果。

### 压缩

无损压缩的本质是消除统计冗余——利用数据中的重复模式，用更短的编码替代。一旦冗余被榨干，文件对压缩算法来说就跟随机数据一样，再压缩只会加上压缩格式自身的元数据开销，反而变大。
有损压缩则直接丢弃人感知不到的信息（高频声、细微色差等），这部分数据不可恢复。

### Windows

MSI（Microsoft Installer，微软安装器，现称 Windows Installer）。
与普通的 `.exe` 安装程序相比，`.msi` 文件包含规范的安装指令和数据库。
它支持三个核心能力：
- 更干净的卸载（安装过程被完整记录，可完全回滚）
- 企业大批量网络静默安装;;无需人工点击（`msiexec /i package.msi /qn`）
- 自动修复损坏的软件组件（检测到文件缺失时自动从安装源恢复）

虚拟机磁盘是动态分配的（thin provision），用多少长多大。在虚拟机里"删除文件"对宿主机来说其实是写操作——因为删除只是修改文件系统的元数据（把对应区块标记为"空闲"），这些元数据本身存在虚拟磁盘上，标记动作会触发对虚拟磁盘的写入。如果虚拟磁盘是动态的，大量删除甚至可能导致虚拟磁盘文件变大。

### 算法趣闻

**猴子排序（Bogo-Sort / Monkey Sort）**，也被戏称为"无限猴子排序"或"愚蠢排序"，是一种纯粹基于**随机概率**的恶搞型排序算法。
它的核心思想来自于著名的"无限猴子定理"：如果让一只猴子在打字机上随机敲击键盘，只要时间足够长，它最终一定能敲出一部《莎士比亚全集》。

递归的机制是利用系统底层的函数调用栈 call stack

### 其他

DataTable 提供了实例方法 Compute，能根据提供的数学表达式参数进行计算。DataTable 类是为了配合数据库使用的，常用来接收数据库里查询出来的表格数据。
