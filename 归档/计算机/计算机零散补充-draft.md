## 2026.5.10 — Unity 项目文件管理

Unity 项目是按文件类型建一级目录，必要时在类型目录下按功能分子目录：
- Scripts/ — 代码
- Scenes/ — 场景
- Prefabs/ — 预制体
- Animations/ — 动画片段
- Animators/ — 动画状态机
- Sprites/ — 图片资源
- Docs/ — 文档
- Audio/、Materials/、Editor/、Plugins/、Resources/

## 2026.5.10 — 爬虫（Web Spider）

本质：模拟浏览器行为，按规则批量抓公开数据，替代人工复制粘贴。

工作流程：
- **种子 URL**：起始网址（如首页、列表页）。
- **发 HTTP 请求**：用 `requests`/`curl` 模拟浏览器访问，带 Headers（User-Agent、Cookie）。
- **获取响应**：服务器返回 HTML/JSON/图片等原始内容。
- **解析提取**：用 XPath、CSS 选择器、正则或 BeautifulSoup 抓目标字段（标题、价格、链接）。
- **存储 + 翻页**：存 CSV/JSON/数据库；从页面抓新 URL 入队列，循环爬取。

为什么有些视频的下载按钮是灰色的，爬虫能无视这个直接下载原视频？
用 Playwright + Chromium 能完整加载视频流，不管网站禁不禁止下载（下载按钮是灰色其实是前端限制），视频源码一定会渲染到浏览器里。

### 压缩

无损压缩的本质是消除统计冗余——利用数据中的重复模式，用更短的编码替代。一旦冗余被榨干，文件对压缩算法来说就跟随机数据一样，再压缩只会加上压缩格式自身的元数据开销，反而变大。
有损压缩则直接丢弃人感知不到的信息（高频声、细微色差等），这部分数据不可恢复。

### Windows

MSI（Microsoft Installer，微软安装器，现称 Windows Installer）。
与普通的 `.exe` 安装程序相比，`.msi` 文件包含规范的安装指令和数据库。
它支持三个核心能力：
- 更干净的卸载（安装过程被完整记录，可完全回滚）
- 企业大批量网络静默安装;;无需人工点击（`msiexec /i package.msi /qn`）
- 自动修复损坏的软件组件（检测到文件缺失时自动从安装源恢复）

虚拟机磁盘是动态分配的（thin provision），用多少长多大。在虚拟机里"删除文件"对宿主机来说其实是写操作——因为删除只是修改文件系统的元数据（把对应区块标记为"空闲"），这些元数据本身存在虚拟磁盘上，标记动作会触发对虚拟磁盘的写入。如果虚拟磁盘是动态的，大量删除甚至可能导致虚拟磁盘文件变大。

### 算法趣闻

**猴子排序（Bogo-Sort / Monkey Sort）**，也被戏称为"无限猴子排序"或"愚蠢排序"，是一种纯粹基于**随机概率**的恶搞型排序算法。
它的核心思想来自于著名的"无限猴子定理"：如果让一只猴子在打字机上随机敲击键盘，只要时间足够长，它最终一定能敲出一部《莎士比亚全集》。

递归的机制是利用系统底层的函数调用栈 call stack

#补充-flashcards

```csharp
(int)(size / factor)
```
该式是否会向上取整，如果factor是2的幂次方常量，编译器是否会优化该代码
?
- 前面的int强制转换会直接扔掉所有小数部分，只保留整数部分，结果是向下取整。
- 如果factor是编译器就能确定的常量，编译器会将该代码翻译成CPU的位移指令，这会比DIV指令快出几十倍的性能。
