## 引入：为什么要半边？

### 从网格说起

你做 CAD，肯定见过这种结构——三角网格（Mesh）：

![[dot/半边-动机.svg]]

一个网格无非三样东西：**顶点**、**边**、**面**。最简单的存法是用数组：

```csharp
// 朴素表示1：分别存
Vector3[] vertices = { V0, V1, V2, V3 };
int[][] faces = {
    new[] {0, 1, 2},  // Face 0: V0-V1-V2
    new[] {0, 2, 3},  // Face 1: V0-V2-V3
    new[] {0, 3, 1},  // Face 2: V0-V3-V1
    new[] {1, 3, 2},  // Face 3: V1-V3-V2
};
```

> [!warning] 问题
> 这种表示法，做下面这些操作全是 **O(n)**：
> - "这条边被哪两个面共享？" → 遍历所有面的所有边
> - "这个顶点周围有哪些面？" → 遍历所有面
> - "从一个面走到相邻面？" → 同上
>
> CAD 里网格编辑（拉伸面、删除顶点、边塌缩）频繁需要这些查询，O(n) 根本撑不住。

---

### 三个核心查询

半边数据结构的设计目标很明确——让下面三个操作做到 **O(1)**：

| 查询 | 输入 | 输出 | CAD 场景 |
|:---|:---|:---|:---|
| 边的相邻面 | 一条边 | 共用这条边的 1 或 2 个面 | 判断边是不是边界边（只有 1 个面 = 边界） |
| 顶点的相邻面 | 一个顶点 | 围绕该顶点的所有面（按顺序） | 顶点平滑、删除顶点 |
| 面的相邻面 | 一个面 | 与该面共边的所有面 | 面拉伸、面偏移 |

> [!NOTE] 类比：双向链表
> 单向链表你有 next，要找 prev 只能从头扫。加了 prev 指针后，O(n) 变 O(1)。
> 半边结构的思路完全一样——**多存指针，换查询速度**。
> 区别在于网格是二维的邻接关系，需要的指针种类比一维链表多。

## 核心洞察：把边撕成两半

### 一条边 = 两条半边

![[dot/半边-半边拆分.svg]]

想象网格中一条边被两个面共享：

```
面 F0  (左侧)          面 F1 (右侧)
    ↓                     ↓
  V0 ────────────→ V1    V1 ────────────→ V0
    这条半边属于 F0        这条半边属于 F1
```

> [!important] 关键
> 一条几何上的"边"被**拆成两条方向相反**的**半边 (Half-Edge)**。
> - 每条半边属于**恰好一个面**
> - 两条半边互为 **Pair（对边）**
> - 半边有方向（从 Origin 指向"下一个顶点"）

**类比**：一条双向街道拆成两条单行道——每条单行道属于一个街区。

### 半边 = 环绕一个面的"单链表"

一个面由多条半边围成，按同一个方向（逆时针）首尾相连：

```
Face (逆时针方向):
   V0 ──he0──▶ V1 ──he1──▶ V2 ──he2──▶ V0
   ↑                                    │
   └──────────── he2 ───────────────────┘
   
   每条半边存：
   - Origin: 起点（如 he0.Origin = V0）
   - Next:   下一条半边（he0.Next = he1）
   - Prev:   上一条半边（he1.Prev = he0）
   - Face:   所属的面
   - Pair:   对面的半边（反向的那条）
```

> [!NOTE] 方向约定
> 本文约定：从**面外侧看进去**，半边是**逆时针 (CCW)** 方向。
> 这意味着面法线指向观察者时，半边逆时针绕行。
> 这是计算机图形学的通用约定（与 OpenGL 一致）。

## 数据结构定义（C#）

### 四个类

```csharp
public class HEVertex
{
    public Vector3 Position { get; set; }
    // 从该顶点出发的任意一条半边（随便哪条都行）
    // 通过它可以"转动一圈"找到所有从该顶点出发的半边
    public HalfEdge Edge { get; set; }
}

public class HalfEdge
{
    public HEVertex Origin { get; set; }   // 半边起点
    public HalfEdge Pair   { get; set; }   // 反向的那条半边（对面那条）
    public HalfEdge Next   { get; set; }   // 同一个面内的下一条半边
    public HalfEdge Prev   { get; set; }   // 同一个面内的上一条半边
    public HEFace    Face  { get; set; }   // 所属的面
}

public class HEFace
{
    // 围成这个面的任意一条半边（随便哪条都行）
    // 通过它 "+ Next" 可以绕面走一圈
    public HalfEdge Edge { get; set; }
}

public class HEMesh
{
    public List<HEVertex>  Vertices   { get; set; } = new();
    public List<HalfEdge>  HalfEdges  { get; set; } = new();
    public List<HEFace>    Faces      { get; set; } = new();
}
```

### 字段职责表

| 字段 | 所属类 | 含义 | 为什么需要它 |
|:---|:---|:---|:---|
| `Origin` | HalfEdge | 半边从哪个顶点出发 | 知道边的起点；绕顶点遍历时判断"我是不是从这个顶点出发" |
| `Pair` | HalfEdge | 同一条几何边的另一条半边 | 跨面跳转：从 F0 走到相邻的 F1 |
| `Next` | HalfEdge | 同面内下一段半边 | 沿面周游：绕面走一圈 |
| `Prev` | HalfEdge | 同面内上一段半边 | 反向周游 + 绕顶点遍历时需要 |
| `Face` | HalfEdge | 所属的面 | 从边直接知道"我在哪个面上" |
| `Edge` | HEVertex | 该顶点发出的一条半边 | 从顶点出发遍历所有相邻面/边 |
| `Edge` | HEFace | 围成面的一条半边 | 从面出发遍历所有顶点/边 |

> [!help] 为什么 Vertex 和 Face 都只存"任意一条"半边？
> 因为只要有一条，就能通过 Next/Pair/Prev 组合走到所有关联的半边。
> 类比：链表你只需要 head，就能走到所有节点。
>

## 不变量（Invariants）

> [!important] 不变量 = 永远成立的规则
> 这些规则是半边结构的"宪法"。建网格时必须满足，遍历算法依赖它们。

| # | 不变量 | 含义 | 如果违反 |
|:---|:---|:---|:---|
| 1 | `e.Next.Prev == e` | Next 和 Prev 必须互逆 | 单向走到某处后回不来 |
| 2 | `e.Pair.Pair == e` | Pair 必须互逆 | 跨面跳转方向混乱 |
| 3 | `e.Pair.Origin == e.Next.Origin` | 对边的终点 = 下一条半边的起点 | 几何不闭合，面有缺口 |
| 4 | `e.Face == e.Next.Face` | 同一面的所有半边指向同一个 Face | 同面内走丢了 |
| 5 | 绕 `e = e.Next` 走一圈，回到起点 | 面的半边构成闭环 | 面不封闭 |
| 6 | `v.Edge.Origin == v` | 顶点存储的半边确实从自己出发 | 顶点遍历死循环 |
| 7 | 每条几何边恰好有 2 条（或 1 条）半边 | 流形 (manifold) 条件 | 非流形网格（本文不讲） |

> [!NOTE] Pair 为什么可能只有 1 条？
> 当边位于网格**边界**时，它只有一个面，Pair = null。
> 本文聚焦闭合网格（每条边恰好 2 个面），边界情况暂不展开。

### 手动验证一例

假设面 ABC，逆时针，半边为 he0(A→B), he1(B→C), he2(C→A)：

| 半边 | Next | Prev | Pair |
|:---|:---|:---|:---|
| he0 (A→B) | he1 | he2 | 另一条 B→A 的半边 |
| he1 (B→C) | he2 | he0 | 另一条 C→B 的半边 |
| he2 (C→A) | he0 | he1 | 另一条 A→C 的半边 |

验证不变 1：`he0.Next.Prev = he1.Prev = he0` ✓
验证不变 3：`he0.Pair.Origin = (B→A).Origin = B = he1.Origin` ✓

## 核心遍历操作（配跟踪表）

> [!important] 三个最基础的遍历
> 下面的遍历是所有网格编辑操作（增删顶点、翻转边、拉伸面）的积木。
> 每一段都配了手动跟踪表——**建议拿纸笔跟着走一遍**。

### 遍历 1：绕面走一圈（Face → 全部顶点）

```csharp
List<HEVertex> GetFaceVertices(HEFace face)
{
    var result = new List<HEVertex>();
    var start = face.Edge;       // 从任意一条半边开始
    var current = start;
    
    do
    {
        result.Add(current.Origin);   // 每条半边的起点就是面上的一个顶点
        current = current.Next;       // 沿 Next 前进
    } while (current != start);       // 绕一圈回来
    
    return result;
}
```

**跟踪表**：假设 face.Edge = he0(A→B)

| 迭代 | current | current.Origin | 加入 result | current.Next |
|:---|:---|:---|:---|:---|
| 第 1 轮 | he0 (A→B) | A | [A] | he1 |
| 第 2 轮 | he1 (B→C) | B | [A, B] | he2 |
| 第 3 轮 | he2 (C→A) | C | [A, B, C] | he0 |
| 循环结束 | he0 == start，退出 | | 最终: [A, B, C] | |

---

### 遍历 2：绕顶点走一圈（Vertex → 全部相邻面）

这是半边结构最精妙的遍历。思路：

```
从顶点 V 出发，有一条半边 e（e.Origin == V）。
e 属于面 F0。要走到下一个共享 V 的面：
  step 1: e = e.Prev      // 走到同一个面的"前一条"半边
  step 2: e = e.Pair      // 跳到对面的半边（跨越到相邻面）
  此时 e 就是从 V 出发、属于面 F1 的半边！
```

> [!help] 为什么是 Prev + Pair？
> ![[dot/半边-指针关系.svg]]
> 看图——从 V 出发的半边 e，它在面 F0 中。
> - e.Prev 是 F0 中**指向 V** 的那条半边（终点是 V）
> - e.Prev.Pair 是它的反向，从 V 出发，属于面 F1
> 
> 所以 **Prev + Pair = 从一个面跳到相邻面，而且仍在 V 出发的半边上**。

```csharp
List<HEFace> GetFacesAroundVertex(HEVertex vertex)
{
    var result = new List<HEFace>();
    var start = vertex.Edge;   // 从顶点出发的任意半边
    var current = start;
    
    do
    {
        result.Add(current.Face);         // 这条半边所属的面
        current = current.Prev.Pair;       // 跳到下一个相邻面的对应半边
    } while (current != start);
    
    return result;
}
```

**跟踪表**：假设顶点 A 周围有 Face0(ABC), Face1(ACD), Face2(ADB)：

```
Face0: he_ABC(A→B) → he_BC(B→C) → he_CA(C→A) → he_ABC...
Face1: he_ACD(A→C) → he_CD(C→D) → he_DA(D→A) → he_ACD...
Face2: he_ADB(A→D) → he_DB(D→B) → he_BA(B→A) → he_ADB...

Pair 关系:
  he_CA.Pair = he_ACD  (C→A vs A→C)   ← 注意：C→A 的 Pair 是 A→C
  he_DA.Pair = he_ADB  (D→A vs A→D)
  he_BA.Pair = he_ABC  (B→A vs A→B)
```

设 vertex.Edge = he_ABC (A→B)：

| 迭代 | current | current.Face | current.Prev | current.Prev.Pair (= 下一个 current) |
|:---|:---|:---|:---|:---|
| 第 1 轮 | he_ABC (A→B) | Face0 | he_CA (C→A) | he_CA.Pair = he_ACD (A→C) |
| 第 2 轮 | he_ACD (A→C) | Face1 | he_DA (D→A) | he_DA.Pair = he_ADB (A→D) |
| 第 3 轮 | he_ADB (A→D) | Face2 | he_BA (B→A) | he_BA.Pair = he_ABC (A→B) |
| 循环结束 | he_ABC == start，退出 | | | |

最终：Face0, Face1, Face2 ✓（顶点 A 周围的三个面）

### 遍历 3：找出共用一条边的两个面

```csharp
(HEFace face1, HEFace face2) GetFacesOfEdge(HalfEdge edge)
{
    var face1 = edge.Face;
    var face2 = edge.Pair?.Face;  // Pair 为 null 时 = 边界边，只有一个面
    return (face1, face2);
}
```

这是半边结构中最简单的查询——O(1)，不需要任何循环。

### 遍历 4：面的所有相邻面

```csharp
List<HEFace> GetAdjacentFaces(HEFace face)
{
    var result = new List<HEFace>();
    var start = face.Edge;
    var current = start;
    
    do
    {
        var neighbor = current.Pair?.Face;  // 对边所属的面
        if (neighbor != null)
            result.Add(neighbor);
        current = current.Next;
    } while (current != start);
    
    return result;
}
```

**跟踪表**：Face0(ABC) 的半边和邻面（假设 Face0 与 Face1 共享 AB，与 Face2 共享 BC，与 Face3 共享 CA）：

| 迭代 | current | current.Pair?.Face |
|:---|:---|:---|
| 第 1 轮 | he_AB (A→B) | Face1 |
| 第 2 轮 | he_BC (B→C) | Face2 |
| 第 3 轮 | he_CA (C→A) | Face3 |

最终：[Face1, Face2, Face3]——Face0 的三个相邻面。

## 手工构建：一个四面体

> [!NOTE] 目的
> 这部分让你从零建一个四面体的半边结构——用什么数据结构，每条字段怎么填。
> 跟着跟踪表走，理解"建立连接"的完整过程。

### 顶点和面

![[dot/半边-四面体.svg]]

顶点：A(0,0,0), B(1,0,0), C(0,1,0), D(0,0,1)

四面体有 4 个三角面。为确保每个几何边恰好有方向相反的两条半边，面的方向需要协调：
- 面的法线指向**四面体外部**
- 从外部看是逆时针

约定以下面的顶点顺序（已验证法线指向外部）：

| 面 | 顶点顺序 | 正常方向 |
|:---|:---|:---|
| Face0 (ABC) | A → C → B | −z（底面向下） |
| Face1 (ABD) | B → D → A | （右侧向外） |
| Face2 (ACD) | D → C → A | （左侧向外） |
| Face3 (BCD) | B → C → D | （背面向外） |

### 步骤 1：创建顶点

```csharp
var mesh = new HEMesh();
var A = new HEVertex { Position = new Vector3(0, 0, 0) };
var B = new HEVertex { Position = new Vector3(1, 0, 0) };
var C = new HEVertex { Position = new Vector3(0, 1, 0) };
var D = new HEVertex { Position = new Vector3(0, 0, 1) };
mesh.Vertices.AddRange(new[] { A, B, C, D });
```

### 步骤 2：为每个面创建半边

先不管 Pair，只建半边链表和 Face：

```csharp
// 辅助方法：为一个面创建 3 条半边，返回它们（按顺序）
(HalfEdge, HalfEdge, HalfEdge) CreateHalfEdgesForFace(
    HEVertex v0, HEVertex v1, HEVertex v2, HEFace face)
{
    var he0 = new HalfEdge { Origin = v0, Face = face };
    var he1 = new HalfEdge { Origin = v1, Face = face };
    var he2 = new HalfEdge { Origin = v2, Face = face };
    
    // 连接 Next/Prev 环
    he0.Next = he1; he1.Next = he2; he2.Next = he0;
    he0.Prev = he2; he1.Prev = he0; he2.Prev = he1;
    
    face.Edge = he0;           // 面指向任意一条半边
    
    return (he0, he1, he2);
}
```

### 步骤 3：为每个面调用

```csharp
var face0 = new HEFace(); mesh.Faces.Add(face0);
var face1 = new HEFace(); mesh.Faces.Add(face1);
var face2 = new HEFace(); mesh.Faces.Add(face2);
var face3 = new HEFace(); mesh.Faces.Add(face3);

var (f0_AC, f0_CB, f0_BA) = CreateHalfEdgesForFace(A, C, B, face0);
var (f1_BD, f1_DA, f1_AB) = CreateHalfEdgesForFace(B, D, A, face1);
var (f2_DC, f2_CA, f2_AD) = CreateHalfEdgesForFace(D, C, A, face2);
var (f3_BC, f3_CD, f3_DB) = CreateHalfEdgesForFace(B, C, D, face3);

mesh.HalfEdges.AddRange(new[] {
    f0_AC, f0_CB, f0_BA,
    f1_BD, f1_DA, f1_AB,
    f2_DC, f2_CA, f2_AD,
    f3_BC, f3_CD, f3_DB,
});
```

### 步骤 4：建立 Pair 关系

现在半边都创建了，但 Pair 还全是 null。需要**找到共边的两条反向半边**并配对。

怎么找？两条半边互为 Pair，当且仅当：
- `he1.Origin == he2.Next.Origin`（he1 的起点 = he2 的终点）
- `he2.Origin == he1.Next.Origin`（he2 的起点 = he1 的终点）
- 也就是：一条从 X→Y，另一条从 Y→X

> [!NOTE] 实际工程中
> 建 Pair 不会用 O(n²) 循环去匹配——通常建 mesh 时，用一个 `Dictionary<(int,int), HalfEdge>` 按 (起点索引, 终点索引) 查找。但理解原理时，先看手动匹配。

**手动匹配表**（12 条半边 → 6 对 Pair）：

| 半边 | 方向 | 反向半边 | 方向 |
|:---|:---|:---|:---|
| f0_AC | A→C | f2_CA | C→A |
| f0_CB | C→B | f3_BC | B→C |
| f0_BA | B→A | f1_AB | A→B |
| f1_BD | B→D | f3_DB | D→B |
| f1_DA | D→A | f2_AD | A→D |
| f2_DC | D→C | f3_CD | C→D |

```csharp
f0_AC.Pair = f2_CA; f2_CA.Pair = f0_AC;
f0_CB.Pair = f3_BC; f3_BC.Pair = f0_CB;
f0_BA.Pair = f1_AB; f1_AB.Pair = f0_BA;
f1_BD.Pair = f3_DB; f3_DB.Pair = f1_BD;
f1_DA.Pair = f2_AD; f2_AD.Pair = f1_DA;
f2_DC.Pair = f3_CD; f3_CD.Pair = f2_DC;
```

### 步骤 5：设置顶点的半边

```csharp
// 每个顶点随便挑一条从自己出发的半边
A.Edge = f0_AC;   // A→C
B.Edge = f0_BA;   // B→A
C.Edge = f0_CB;   // C→B
D.Edge = f1_DA;   // D→A
```

### 构建后的验证

让我们随机挑一个边，验证所有不变量在四面体上成立。以 **边 AC** 为例（f0_AC 和 f2_CA 互为 Pair）：

```csharp
var e = f0_AC;  // A→C, Face0

// 不变量 1: Next.Prev == self
Debug.Assert(e.Next.Prev == e);  // f0_CB.Prev = f0_AC ✓

// 不变量 2: Pair.Pair == self
Debug.Assert(e.Pair.Pair == e);  // f2_CA.Pair = f0_AC ✓

// 不变量 3: Pair 的 Origin = Next 的 Origin
Debug.Assert(e.Pair.Origin == e.Next.Origin);  
// f2_CA.Origin = C,  f0_CB.Origin = C ✓

// 不变量 6: 顶点出发的半边确实从自己出发
Debug.Assert(A.Edge.Origin == A);  // f0_AC.Origin = A ✓
```

## 完整的 Mesh 构建器

把上面的步骤整合成一个可复用的类：

```csharp
public class HEMeshBuilder
{
    private HEMesh _mesh = new();
    private Dictionary<(int, int), HalfEdge> _edgeMap = new();

    /// <summary>
    /// 添加一个三角面。自动创建半边并配对。
    /// </summary>
    public HEFace AddTriangle(int i0, int i1, int i2)
    {
        // 确保顶点索引存在
        while (_mesh.Vertices.Count <= Math.Max(i0, Math.Max(i1, i2)))
            _mesh.Vertices.Add(new HEVertex { Position = Vector3.Zero });

        var face = new HEFace();
        _mesh.Faces.Add(face);

        // 创建三条半边
        var he0 = new HalfEdge { Origin = _mesh.Vertices[i0], Face = face };
        var he1 = new HalfEdge { Origin = _mesh.Vertices[i1], Face = face };
        var he2 = new HalfEdge { Origin = _mesh.Vertices[i2], Face = face };

        // Next/Prev 环
        he0.Next = he1; he1.Next = he2; he2.Next = he0;
        he0.Prev = he2; he1.Prev = he0; he2.Prev = he1;

        face.Edge = he0;
        _mesh.Vertices[i0].Edge = he0;
        _mesh.Vertices[i1].Edge = he1;
        _mesh.Vertices[i2].Edge = he2;

        // 用字典查找/建立 Pair
        TryPair(he0, i0, i1);
        TryPair(he1, i1, i2);
        TryPair(he2, i2, i0);

        _mesh.HalfEdges.AddRange(new[] { he0, he1, he2 });
        return face;
    }

    private void TryPair(HalfEdge he, int from, int to)
    {
        var key = (to, from);  // 查找反向的半边
        if (_edgeMap.TryGetValue(key, out var opposite))
        {
            he.Pair = opposite;
            opposite.Pair = he;
            _edgeMap.Remove(key);  // 配好就删，每条边只配一次
        }
        else
        {
            _edgeMap[(from, to)] = he;  // 暂时没找到反向的，存着
        }
    }

    public HEMesh Build() => _mesh;
}
```

**使用**：

```csharp
var builder = new HEMeshBuilder();
builder.Vertices[0].Position = new Vector3(0, 0, 0);  // A
builder.Vertices[1].Position = new Vector3(1, 0, 0);  // B
builder.Vertices[2].Position = new Vector3(0, 1, 0);  // C
builder.Vertices[3].Position = new Vector3(0, 0, 1);  // D

// 用和前面一致的面朝向
builder.AddTriangle(0, 2, 1);  // Face0: A-C-B
builder.AddTriangle(1, 3, 0);  // Face1: B-D-A
builder.AddTriangle(3, 2, 0);  // Face2: D-C-A
builder.AddTriangle(1, 2, 3);  // Face3: B-C-D

var mesh = builder.Build();
```

> [!NOTE] TryPair 的时间复杂度
> 字典查找 O(1)，所以构建整个 mesh 是 O(n)（n = 半边数 = 3 × 面数）。
> 这就是为什么工程中不用 O(n²) 暴力匹配。

## 回到 CAD

### 半边结构与 B-rep

你用的 CAD 内核（AutoCAD 的 ASM/Acis、SolidWorks 的 Parasolid）内部使用 **边界表示法 (B-rep, Boundary Representation)**。

B-rep 的核心数据结构本质上就是半边结构的扩展版：

| 半边结构 | B-rep 对应 | 差异 |
|:---|:---|:---|
| HalfEdge | CoEdge / HalfEdge | B-rep 增加了曲线几何、容差信息 |
| HEVertex | Vertex | B-rep 的顶点包含精确的几何参数（uv 坐标等） |
| HEFace | Face | B-rep 的面可以有洞 (loop)、曲面几何 |
| HEMesh | Body/Lump/Shell | B-rep 的层级更深：Body → Lump → Shell → Face → Loop → CoEdge → Edge → Vertex |

> [!important] 你学半边结构，就是在学 B-rep 的"骨架"
> 等你理解了半边的遍历和构建，再去看 CAD 内核的 `getAdjacentFaces()`, `getEdgesOfVertex()` 这些 API，就知道它们底层在干什么了。

### 实际 CAD 开发中的应用

- **STL 文件读写**：STL 是纯三角形列表 + 法线，没有邻接信息。读入后构建半边结构，才能做网格编辑
- **网格简化**（减少三角面数）：每个操作（边塌缩、顶点合并）都需要半边遍历
- **布尔运算**：A 和 B 两个实体做并/交/差，底层是面-面求交 + 半边重连
- **偏移/抽壳**：需要遍历所有面 → 沿法线偏移 → 重建半边连接

## 闪卡

> [!question]- 半边结构的核心思想是什么？
> 把几何上的一条边拆成两条方向相反的半边，每条半边属于一个面。通过 Pair 指针关联反向半边，实现跨面的 O(1) 跳转。

> [!question]- 半边结构的四个主要类是什么？各自存什么？
> HEVertex（位置 + 一条出发半边），HalfEdge（Origin, Pair, Next, Prev, Face），HEFace（一条围边），HEMesh（三者的集合）。

> [!question]- 绕顶点走一圈的遍历公式是什么？
> `current = current.Prev.Pair`，重复直到回到起点。Prev 走到同面内指向该顶点的半边，Pair 跳到对侧面的对应半边。

> [!question]- Pair 什么时候是 null？
> 当边位于网格边界时——只有一个面共享这条边。闭合网格中每条边恰好有一对 Pair。

> [!question]- 构建半边结构时，如何高效配对？
> 用 `Dictionary<(from, to), HalfEdge>` 存暂时未配对的半边。每新建一条半边时，查字典中是否有反向的 key = (to, from)。有则配对并删除，无则插入自己。
