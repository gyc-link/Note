IEnumerable`<IGrouping<TKey, TSource>>` ==GroupBy==`<TSource, TKey>`
(
this IEnumerable`<TSource>` source,
Func`<TSource, TKey>` keySelector
)
- 传一个方法 keySelector，用来指定 ==1;;source 集合中每个元素的什么值作为 key==。
- 返回一个集合，集合里每个元素的类型是 IGrouping<TKey, TSource>。
- IGrouping 本身也是一个集合，因为它实现了 ==1;;`IEnumerable<TSource>`==。
- TSource 一开始是 source 集合里元素的类型。  分组以后，每个 IGrouping 里面装的也是 TSource。
- TKey 是这组元素的==1;;标签==。
<!--SR:!2026-09-19,85,270-->

`GroupBy` 和 `ToLookup` 都是分组。  
`GroupBy` 返回 `IEnumerable<IGrouping<TKey,TSource>>`，只能当作一堆组来遍历。  
`ToLookup` 返回 `ILookup<TKey,TSource>`，除了能遍历，还多了 `Count`、`Contains(key)`、`lookup[key]`，所以可以直接根据 key 拿到某一组。

Dictionary`<TKey, TElement>`  ==ToDictionary==`<TSource, TKey, TElement>`
(
this IEnumerable`<TSource>` source,
Func`<TSource, TKey>` keySelector，
Func`<TSource, TElement>` elementSelector
)
里面传两个方法，==1;;分别指定source集合中某一个元素的什么值作为key，和这个元素的什么值作为element==，返回一个字典。如果不指定后者，则代表把这个元素==1;;本身作为value==存进字典。
需要注意这个方法必须确保==1;;指定的key不能重复，且不能为空。因为字典的要求就是key不重复，不空==
