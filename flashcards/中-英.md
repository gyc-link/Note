# 中 → 英 词汇卡片

首字母小写、后续每个单词首字母大写的命名方式
?
- **英文**：camelCase
- **音标**：/ˈkæm.əl/
- **提示**：camel（骆驼）。像骆驼背部的驼峰，低-高-低-高的起伏形状。`firstName`、`getUserById` 都是 camelCase。
<!--SR:!2026-10-19,90,271-->

每个单词首字母都大写的命名方式
?
- **英文**：PascalCase
- **音标**：/ˈpæs.kəl/
- **提示**：以法国数学家 Pascal 命名。所有单词首字母大写，像大写标题。`PersonService`、`GetUserById` 都是 PascalCase。
<!--SR:!2026-12-13,129,290-->

C# 中通过 get/set 访问器封装字段的类成员
?
- **英文**：property
- **音标**：/ˈprɒp.ə.ti/
- **提示**：propr（自己的，源自拉丁语 proprius）+ ety（性质、状态）→ 属于自己的东西 → 属性。property 是封装后的字段，对外像变量一样用，内部靠 get/set 控制读写。
<!--SR:!2026-12-28,125,251-->

为代码元素添加元数据的注解机制
?
- **英文**：attribute
- **音标**：/ˈæt.rɪ.bjuːt/
- **提示**：at（向、给）+ tribute（分配、给予）→ 赋予某种特质 → 特性。C# 中用 `[ ]` 贴在类/方法/属性上面，给代码附加额外信息。`[Obsolete]` 告诉编译器「这方法过时了」。
<!--SR:!2026-10-26,66,211-->

类或结构中直接声明的变量，用于存储数据
?
- **英文**：field
- **音标**：/fiːld/
- **提示**：本义是「田地、旷野」→ 一片可以种东西（存数据）的开阔空间。field 是最朴素的存储单元，没有 get/set 包装，直接读写。`private int _age;` 是一个 field。
<!--SR:!2026-09-30,69,231-->

不带小数部分的数字类型
?
- **英文**：integer
- **音标**：/ˈɪn.tɪ.dʒər/
- **提示**：integr（完整、 untouched，与 integral 同源）→ 完整的数 → 整数。没有小数点、没有碎片。int 是其缩写。
<!--SR:!2026-10-19,90,271-->

带小数位的数值类型（32 位）
?
- **英文**：float
- **音标**：/fləʊt/
- **提示**：本义是「漂浮」→ 小数点可以在数字的任何位置「漂移」。3.14 和 31.4 和 314.0 的相对精度一样，只是小数点的位置在 float（浮动）。double 是双精度（64 位）浮点。
<!--SR:!2026-09-24,72,271-->

连续存储的同类型元素集合，通过索引访问
?
- **英文**：array
- **音标**：/əˈreɪ/
- **提示**：源自拉丁语 ad（向）+ 古法语 rai（排、列）→ 排成一行 → 数组。array 在内存里是一块连续的空间，每个元素紧挨着，所以能用 `arr[3]` 直接跳到第 4 个。随机访问 O(1) 的原因就在这里。
<!--SR:!2026-12-07,112,250-->

二维数组或线性代数中的矩形数字方阵
?
- **英文**：matrix
- **音标**：/ˈmeɪ.trɪks/
- **提示**：拉丁语 mater（母亲、子宫）→ 母体、孕育万物的容器 → 矩阵。矩阵就像「数字的子宫」，向量放进去一转，就生出一个新的向量。CAD 里的变换（平移、旋转、缩放）全是矩阵运算。
<!--SR:!2026-12-10,131,291-->

改变对象大小的变换操作
?
- **英文**：scale
- **音标**：/skeɪl/
- **提示**：本义是「梯子、台阶」→ 一步一步往上爬 → 刻度、比例 → 缩放。scale 是「按比例改变」：每个维度乘一个系数。scale(2) 就是每个坐标 ×2。
<!--SR:!2026-09-26,77,271-->

因采样不足导致图像边缘不平滑的阶梯状现象
?
- **英文**：aliasing
- **音标**：/ˈeɪ.li.ə.sɪŋ/
- **提示**：alias（别名、化名）→ 信号「冒充」了别的频率 → 走样、锯齿。采样频率不够高时，高频信号假装成低频信号混进来，在边缘上显出锯齿。反义词 anti-aliasing（抗锯齿）。
<!--SR:!2026-09-19,40,171-->

封装另一个对象、提供更简洁接口的类或结构
?
- **英文**：wrapper
- **音标**：/ˈræp.ər/
- **提示**：wrap（包、裹）+ er（做某事的物）→ 包装纸 → 包装器。wrapper 不改变核心功能，只是在外面包一层更友好的壳。ObjectARX 是 C++ 写的，acdbmgd.dll 是它的 .NET wrapper。
<!--SR:!2026-10-21,65,191-->

唯一标识资源（窗口、文件等）的整数或指针
?
- **英文**：handle
- **音标**：/ˈhæn.dəl/
- **提示**：hand（手）+ le（小工具）→ 把手。你通过门把手开门，程序通过 handle 操作资源。handle 是资源的「身份证号」，拿到了就能操控。CAD 里 ObjectId 是会话内的 handle，Handle（大写 H）是永久随 DWG 保存的。
<!--SR:!2026-11-23,121,291-->

定义了软件组件之间交互协议的缩写，三个字母
?
- **英文**：API
- **音标**：/ˌeɪ.piːˈaɪ/
- **提示**：Application Programming Interface。Interface = inter（之间）+ face（面）→ 两个面之间的接触层 → 接口。API 就是程序之间的「对话窗口」：你按规定格式喊话，它就按规定格式回答。
<!--SR:!2026-09-26,74,270-->

存储代码及版本历史的地方
?
- **英文**：repository
- **音标**：/rɪˈpɒz.ɪ.tər.i/
- **提示**：re（放回）+ posit（放置）+ ory（地方）→ 存放东西的地方 → 仓库。Git repo 就是代码的仓库，每个版本都存着。简称 repo。
<!--SR:!2027-01-05,125,250-->

托管在服务器上、用于团队协作的版本库
?
- **英文**：remote
- **音标**：/rɪˈməʊt/
- **提示**：re（远离）+ mot（移动）→ 移到远处 → 远程的。remote 不是本地硬盘上的仓库，是 GitHub / GitLab 上的那个。`git remote add origin <url>` 就是告诉本地：「远处还有一份在 url 那里」。
<!--SR:!2026-12-13,102,211-->

从远程仓库获取最新提交但不合并到本地的 Git 操作
?
- **英文**：fetch
- **音标**：/fetʃ/
- **提示**：本义「去拿、去取」。fetch 只把远程的东西拿过来看看（下载到本地数据库），不往你当前分支上合并。对比 pull = fetch + merge，一步到位。
<!--SR:!2026-11-21,103,251-->

将源代码编译、链接并打包成可执行文件的过程
?
- **英文**：build
- **音标**：/bɪld/
- **提示**：本义「建造」。编译是 build 的一环：源码 → 编译 → 链接 → 打包 → 可运行。VS 里 Ctrl+Shift+B 就是 Build Solution。
<!--SR:!2026-09-19,70,271-->

一个文字、数字或符号，UTF-16 中通常占 2 或 4 个字节
?
- **英文**：character
- **音标**：/ˈkær.ək.tər/
- **提示**：希腊语 kharaktēr（雕刻的印记）→ 刻在石上的符号 → 字符。char 是其缩写。character 既指「字符」也指「角色、性格」——一个人或一个符号独有的特征。
<!--SR:!2027-01-07,127,251-->

计算机存储的基本单位，由 8 个 bit 组成
?
- **英文**：byte
- **音标**：/baɪt/
- **提示**：bite（咬）的变体，故意把 i 改成 y 以区别于 bit。一口咬下 8 个 bit → byte。8 个 bit 刚好能表示 256 种状态（一个 ASCII 字符）。
<!--SR:!2026-10-28,95,251-->

计算机中最小的数据单位，值为 0 或 1
?
- **英文**：bit
- **音标**：/bɪt/
- **提示**：binary digit（二进制数字）的缩写。bit 是信息的原子——不可再分的最小单元。8 bit = 1 byte。
<!--SR:!2026-12-23,120,251-->



多边形或多面体的角点
?
- **英文**：vertex
- **音标**：/ˈvɜː.teks/
- **提示**：拉丁语 vertere（旋转、转向）→ vertex = 转折点 → 顶点。一条线从这里拐弯。复数 vertices。三角形有 3 个 vertices，立方体有 8 个。
<!--SR:!2026-12-24,125,251-->

由三条及以上线段首尾相连组成的封闭平面图形
?
- **英文**：polygon
- **音标**：/ˈpɒl.i.ɡɒn/
- **提示**：poly（多）+ gon（角，源自希腊语 gonia）→ 多角形。三角形 = triangle（tri=三），四边形 = quadrangle（quad=四），多边形 = polygon（poly=多）。
<!--SR:!2026-10-09,84,270-->

由直线和/或圆弧连接而成的折线或曲线，CAD 常用对象
?
- **英文**：polyline
- **音标**：/ˈpɒl.i.laɪn/
- **提示**：poly（多）+ line（线）→ 多段线。一根 polyline 是一个整体，但里面可以有很多段（segment），每段可以是直线或圆弧。区别于 Line（单独一段直线）。CAD 命令 PLINE。
<!--SR:!2026-09-30,78,271-->

描述多段线中圆弧段弯曲程度和方向的参数
?
- **英文**：bulge
- **音标**：/bʌldʒ/
- **提示**：本义「凸起、鼓包」。bulge 的值 = 圆弧的 1/4 圆心角的正切值 × 方向符号。bulge=0 是直线，bulge=1 是半圆，bulge 为正表示逆时针，为负表示顺时针。多段线用 bulge 而不是存圆弧对象，是因为两个数字（顶点 + bulge）就能描述一段弧，极省空间。
<!--SR:!2026-11-10,83,211-->

通过一组控制点生成的平滑曲线，常用于曲线建模
?
- **英文**：spline
- **音标**：/splaɪn/
- **提示**：源自造船业——用一根有弹性的木条或金属条（叫 spline）压过控制点，自然弯曲成最平滑的形状。CAD 里 spline 也是这个原理：给控制点，算法算出经过它们的最平滑曲线。SPE = SPline Edit。
<!--SR:!2026-10-20,91,271-->

平面内到两个焦点距离之和为常数的点的轨迹
?
- **英文**：ellipse
- **音标**：/ɪˈlɪps/
- **提示**：ellipse 和 ellipsis（省略）→ 椭圆的定义比圆的定义「少了一部分」→ 不完整的圆。圆只有一个焦点（圆心），椭圆有两个。CAD 里 Ellipse 对象用长轴、短轴、中心来描述。
<!--SR:!2026-10-04,55,231-->

CAD 中在封闭区域内填充图案或颜色的操作
?
- **英文**：hatch
- **音标**：/hætʃ/
- **提示**：本义「在表面刻或画很多细密的平行线」→ 阴影线 → 填充。CAD 里 Hatch 是在封闭区域内打上图案（斜线、格子、实体色）。Hatch 命令用于表示材料类型、剖面等。
<!--SR:!2026-09-16,57,231-->

显示图形对象大小或位置的标注
?
- **英文**：dimension
- **音标**：/daɪˈmen.ʃən/
- **提示**：di（分开）+ mens（测量）+ ion → 量出来的跨度 → 尺寸、维度。CAD 里 dimension 是标注对象的统称：线性标注、径向标注、角度标注等都继承自 Dimension 基类。
<!--SR:!2026-10-10,81,271-->

测量角度的单位
?
- **英文**：angle unit
- **音标**：/ˈæŋ.ɡəl ˈjuː.nɪt/
- **提示**：angle（角，源自拉丁语 angulus「弯角」）+ unit（单位）。度（degree）= 圆周的 1/360，弧度（radian）= 弧长等于半径的角。CAD 默认用度，但很多 API 内部用弧度。
<!--SR:!2026-10-03,79,271-->

1 弧度 ≈ 57.3° 的角度度量单位
?
- **英文**：radian
- **音标**：/ˈreɪ.di.ən/
- **提示**：radius（半径）+ ian（属于）→ 跟半径有关的角 → 弧度。弧长 = 半径 × 弧度值。一个完整的圆周 = 2π 弧度 ≈ 6.283 弧度。CAD API 里三角函数几乎全用弧度。
<!--SR:!2027-01-19,139,251-->

圆的周长
?
- **英文**：circumference
- **音标**：/səˈkʌm.fər.əns/
- **提示**：circum（环绕）+ fer（携带、运送）+ ence → 绕一圈的长度 → 圆周。circumference = 2πr。circum 前缀也出现在 circumstance（环境 = 站在周围的事）。
<!--SR:!2026-12-22,123,251-->

封闭图形边界的总长度
?
- **英文**：perimeter
- **音标**：/pəˈrɪm.ɪ.tər/
- **提示**：peri（周围，源自希腊语）+ meter（测量）→ 测量外围 → 周长。perimeter 泛指任何封闭图形的边界长度，不限于圆。圆的 perimeter 也叫 circumference。
<!--SR:!2026-10-14,58,191-->

从圆心到圆周的距离
?
- **英文**：radius
- **音标**：/ˈreɪ.di.əs/
- **提示**：拉丁语「射线、轮辐」→ 从中心向四周辐射 → 半径。radius 是圆心到圆周，diameter 是穿过圆心的两端距离 = 2×radius。
<!--SR:!2026-09-12,57,231-->

用极径（距离）和极角（角度）表示点的坐标系
?
- **英文**：polar
- **音标**：/ˈpəʊ.lər/
- **提示**：pole（极点）+ ar → 跟极点有关的 → 极坐标。不同于直角坐标（x, y），polar 用（距离, 角度）描述位置。北极（North Pole）就是地球的「极点」。
<!--SR:!2026-09-25,73,271-->

既表示「圆形的」又表示「循环的」
?
- **英文**：circular
- **音标**：/ˈsɜː.kjə.lər/
- **提示**：circle（圆）+ ar（形容词后缀）→ 圆的。circular queue = 循环队列（头和尾接在一起），circular arc = 圆弧。circular 的核心画面是「绕一圈回到原点」。
<!--SR:!2026-12-17,120,250-->

数学中表示垂直；数据结构中十字链表
?
- **英文**：orthogonal
- **音标**：/ɔːˈθɒɡ.ən.əl/
- **提示**：ortho（正、直、正确）+ gonal（角）→ 正确的角 = 直角 → 正交。两个向量 orthogonal = 它们的内积为零 = 互相垂直。编程中 orthogonal 也指「各维度独立、互不影响」——好的设计是 orthogonal 的。CAD 里 F8 正交锁定 = Ortho 模式。
<!--SR:!2026-11-12,82,210-->

快速排序中选取基准将数组分成左右两部分的操作
?
- **英文**：partition
- **音标**：/pɑːˈtɪʃ.ən/
- **提示**：part（部分）+ ition（动作、结果）→ 分成几部分 → 分割。快速排序的核心步骤就是 partition：选一个 pivot，把比它小的放左边，比它大的放右边。partition line = 分割线。
<!--SR:!2026-10-23,71,211-->

快速排序中用于分割数组的基准元素
?
- **英文**：pivot
- **音标**：/ˈpɪv.ət/
- **提示**：本义「枢轴、支点」→ 一切围绕它转动的那根轴。快速排序中 pivot 是分界点——所有元素根据与 pivot 的大小关系被分到两边。pivot 选得好，排序效率才高。
<!--SR:!2026-10-17,88,271-->

程序报错中常见的「访问冲突」
?
- **英文**：violation
- **音标**：/ˌvaɪ.əˈleɪ.ʃən/
- **提示**：violate（违反、侵犯）的名词。Access Violation = 访问了不属于你的内存区域 → 操作系统直接杀进程。CAD 二次开发中常见：Dispose 了一个对象后又用它的指针 → Access Violation 闪退。
<!--SR:!2026-12-02,111,251-->

执行数学运算的工具或应用程序
?
- **英文**：calculator
- **音标**：/ˈkæl.kjə.leɪ.tər/
- **提示**：calc（石头、石灰）+ ul（小）+ ator（做某事的工具）→ 用小石头计数的工具 → 计算器。古罗马人用石灰石（calculus）计数，calculate（计算）和 calculus（微积分）都源于此。
<!--SR:!2026-09-25,62,231-->

用于唯一标识函数或方法的名称与参数组合
?
- **英文**：signature
- **音标**：/ˈsɪɡ.nə.tʃər/
- **提示**：sign（标记、签名）+ ature → 签名。方法签名 = 方法名 + 参数类型列表（不含返回值）。在同一作用域内，signature 必须唯一——就像没有两个人的签名完全一样。重载就是同一个方法名但不同 signature。
<!--SR:!2026-09-14,55,231-->

用于命名变量、函数、类、接口等的合法名称
?
- **英文**：identifier
- **音标**：/aɪˈden.tɪ.faɪ.ər/
- **提示**：identify（识别、确认身份）+ er → 标识符。identifier 是代码中你自己起的名字——变量名、函数名、类名。编译器通过 identifier 找到对应的东西。关键字（如 int、class）不能做 identifier。
<!--SR:!2026-11-09,80,211-->

Git 中存放已修改但未提交代码的临时区域
?
- **英文**：Staging Area
- **音标**：/ˈsteɪdʒ.ɪŋ ˈeə.ri.ə/
- **提示**：stage（舞台→暂存→分阶段）+ area（区域）。`git add` 把改动从工作区搬到 Staging Area（暂存区），此时还没真正 commit，就像一个候场区——演员（改动）已经站好位了，等导演喊「Action」（commit）才正式登台。
<!--SR:!2026-11-07,78,211-->

独立复制仓库副本进行开发与修改
?
- **英文**：fork
- **音标**：/fɔːk/
- **提示**：本义「叉子、分叉」。fork 一个仓库 = 把别人的代码「叉」过来，在自己的副本里随便改，不影响原仓库。路走到一个岔路口（fork），你选择了自己的方向。pull request 是把你的 fork 合并回原仓库。
<!--SR:!2026-10-07,82,270-->

对多个集合执行交集、并集、差集等操作
?
- **英文**：Set operation
- **音标**：/set ˌɒp.əˈreɪ.ʃn/
- **提示**：set（集合 = 一堆确定的东西）+ operation（操作）。交集（Intersect）取公共部分，并集（Union）取全部不重复的，差集（Except）取 A 有 B 没有的。LINQ 里三个方法对应三种 Set operation。
<!--SR:!2026-12-04,109,251-->

取多个集合中共同存在的元素
?
- **英文**：intersect
- **音标**：/ˌɪn.təˈsekt/
- **提示**：inter（相互、在中间）+ sect（切、割）→ 互相切入 → 交叉、交集。两个圆相交（intersect）的阴影部分就是 intersection。两个集合 intersect 的结果是两个集合都有的元素。
<!--SR:!2026-10-12,83,270-->

合并多个集合并去除重复元素
